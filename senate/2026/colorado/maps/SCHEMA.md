# Schema and conservation

`inventory.json` contains all3,199 observations in canonical full order, exact ordered priority/remainder keys, literal source keys, historical candidate volumes and full source-object pointers. Every entry references an actual acquired historical Census county context; county PDF and native service references are additional qualified shared-parent references. All leaf/current/legal match flags are false. These display fields never replace complete original objects.

`parent-inventory.json` preserves all64 authorities, original complete-parent/hierarchy pointers, every ordered child, source priority keys and derived remainder children. The original contract did not supply the remainder-child field. The explicit derivation is original full child order filtered by global remainder membership. No source-native codes are converted into unrelated standard IDs. County FIPS selects only county context, not a reporting-leaf geometry.

`historical-conservation.json` pins the complete frozen contract, all26complete companions and35individual original bodies. Runtime validation reads the external acceptance by path only and independently compares every root-field semantic fingerprint and13,174complete recursive object references. Canonical semantics are UTF8 JSON, ensure_ascii=false, sorted dictionary keys, separators comma/colon, allow_nan=false; array order/types/nulls/literals remain significant. JSONL records and CSV headers/all rows are complete. Gzip reconstruction hashes verify whole expanded bytes in memory. Historical source rows include9,831actual native/control objects; the all-candidate extract has101,529positions, native99,514 and numeric-position121,191. Full SSR pageProps,37candidate/pseudocandidate objects, flags/parties/headers/clocks/state presentation polygon, all3,183OOXMLstatsrows/22,281cells/shared-string indices/formulas/attributes, original18emptyDcells,1,043,548cachedtail,192county source/admin rows and390turnout positions remain in complete referenced bodies. A state polygon in SSR is presentation metadata only.

`raw/*.receipt.json` stores requested URL, purpose, parent chain/constructor, UTC, GET, actual HTTP status or transport error, final URL, all response headers, redirects, unknown source clock/status qualification, raw entity byte count/hash and ordered stored-part byte counts/hashes. Requests decodes HTTP content encoding: raw means complete returned entity bytes, not compressed wire capture. A non200/error body is still reconstructed and checked. None indicates transport failure, not HTTP404. `source_clock:null` means unknown; HTTP Date/Last-Modified never silently becomes a geometry effective date. Complete layer editingInfo/PDFmetadata/printed dates are separate.

`raw/*.service.json` inventories source-native service capture IDs and all raw pages. The full page objects include schema/CRS and every feature's complete native attributes/geometry; they are not merged into a GeoJSON projection. OID order and page boundaries remain as captured. Z/M/truecurve flags and all source geometry keys are retained. `qa/service-audit.json` fingerprints complete individual features/geometry and checks all fields;`qa/service-topology.json` explicitly excludes curves. Null/empty/open/invalid/orphan-hole/curve source objects are never removed or repaired. The current captures have no diagnosed invalid/open linear geometry;49Adams curves remain outside linear analysis.

`qa/binary-geometry-audit.json` records originalZIP CRCs and everySHP/SHX/DBF member hash/type/count/offset, DBF descriptor and raw per-field bytes, XYdouble/parts fingerprints and sourceWKT. Every XY is checked bit-for-bit against PyShp. Original files inside ZIPs remain authoritative; no replacement SHP is written. Native topology is only a diagnostic with area in native coordinate units squared; validlinear feature intersections are separate from previews, with no same-vintage legal outline or legal coverage certification.

`pdf-assets.json` lists complete byte-identical PDF reconstructions, original response/ZIPmember, full text extraction, page count/dimensions, PDF metadata/warnings and automatic whole-page previews. Printed vintage and sparse/raster/proposed/municipal limits are in`source-qualifications.json`. PDF metadata creation dates are not boundary approval. Source .xls roster bytes are archived under their receipt; no identity crosswalk is inferred.

`previews/` and HTML pages are derivatives. SVG paths preserve each linear source point/part and use an affine display transform in native coordinates, without simplification. Curved objects stay intact in original JSON and are explicitly excluded from linear previews. PNGs are raster previews. Full sources always remain independently retrievable/reconstructible. `qa/visual-review.json` distinguishes actual selected image viewing from automatic coverage; no browser exercise is asserted.

`asset-manifest.json` seals all worker-owned files including the report, every receipt, failed body, script and QA/history file, excluding only the manifest itself. External original dependencies are individual immutable files; the acceptance remains a path-only authority and does not receive a reverse worker pin.
