# Source, identity and conservation schema

All paths in `acquisition.body_path`, ordered `body_parts`, immutable pins and historical source references are relative to the Colorado state directory. Owned packet filenames without a `data/` prefix are relative to this directory. JSON pointers follow RFC6901; `JSONL_record` is1-based. Native/source IDs are literal strings, including leading/trailing source presentation; they are never parsed into portable geography/candidate IDs.

- `acquisition.json`: complete request records with unique ID, literal URL, URL-escaped actual requested URL, final URL, parent, exact observed anchor/constructor/tuple when applicable, county authority scope, GET, null request body, UTC, status/null transport error, full headers/redirects, complete raw/stored hashes/bytes and immutable body location. A locally unsupported `mailto:` parse has no HTTP response/outreach. Every actual negative response remains complete. Outer deterministic gzip is storage, separate from any HTTP Content-Encoding. Raw hashes describe complete urllib bytes. Immutable reused producer originals retain their own decoded-entity convention in the separate historical original receipt list.
- `source/*.body.gz` or `*.partNNN`: complete content-addressed original bodies, no truncation. A split is an ordered byte split of one complete outer gzip stream; concatenate parts, verify stream SHA/bytes, gzip-decompress, verify raw SHA/bytes. Every individual stored object is strictly below40,000,000 bytes.
- `observed-pages.json.gz`: complete parsed HTML element/attribute list, anchors (literal href, text, actual base-resolved URL), full inline scripts and text. Original HTML remains authoritative for DOM fidelity. Scripts/configs retain all source fields. HTML base URLs, application route IDs and DOM IDs remain different from reporting/candidate keys.
- `response-objects.json.gz`: complete acquired JSON responses and complete SSR `__NEXT_DATA__` payloads, keyed by receipt or receipt plus `#__NEXT_DATA__`. No candidate/control/null/header/pseudo field is projected away. `response-schemas.json.gz` describes every observed recursive path/type, using wildcard array positions; source object values remain complete in originals and this full extraction.
