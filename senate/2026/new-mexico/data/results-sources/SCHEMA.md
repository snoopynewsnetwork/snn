# New Mexico official-source evidence and reconstruction

This is source research. `current_count_admitted` and `current_change_admitted` are false throughout. There is no feed collector, current join, remaining-vote estimator or probability model. Coordinator alone reviews and admits later current evidence.

Authority is identified only by `data/coordinator-source-research-acceptance.json`, relative to the state directory. Its entire body was consumed in memory after the supplied initial byte/SHA verification. This package does not store its body, hash, copy or reverse pin. The exact frozen contract and every required source/schema companion have their own immutable byte references in `immutable-inputs.json`; those are source bodies, not substitutes for authority.

## Original acquisitions

`receipts/<id>.json` records each actual request: literal requested URL, percent-encoded wire URL where captured, observed parent/link or constructor, method, complete submitted public form body where applicable, UTC start/end, initial request headers, redirect sequence, status/reason/error, final URL and full response headers. Each redirect retains its whole entity and response headers. Earlier redirect events did not separately record redirected request headers; those headers are unavailable, not inferred from the initial request. Later acquisition code supports recording them. Header arrays retain repeated names such as `Set-Cookie`. An HTTP-200 error, app shell, access challenge, empty workbook or setup result is not a successful vote observation.

`originals/<raw-SHA256>.gz` holds exactly one complete acquired entity for that raw hash. `body` describes the response entity before explicit Content-Encoding decompression; `decoded_body` describes any decoded entity. Every reference gives stored bytes/SHA, raw bytes/SHA and compression. To recover bytes: read `path` relative to the state directory, verify stored length/SHA, gzip-decompress, then verify raw length/SHA. Transfer framing is not an entity body. No response is truncated. All retained artifacts are strictly below 40,000,000 bytes; no splitting was required. Transient original PDFs used for Poppler are removed. No caches or dependency directories are part of the package.

`pages/<id>.json` is discovery output, not original HTML. It retains href versus printed label, all anchor attributes/positions, scripts, forms, inputs/options and text. `structures/<id>.json.gz` independently parses the complete response and retains all HTML start/end/data events with source line/column, full tables/cells/attributes and text; all CSV rows including trailing empties; entire JSON values; complete XML trees with tag, attributes, text, tail and ordered children; or every XLSX ZIP member's complete UTF-8 XML, ZIP metadata, hashes and XML tree. Raw bytes remain authoritative for exact encoding, delimiters, comments and layout. Declared HTML character encoding/BOM is respected; discovery extracts made before that improvement may have replacement characters, so use raw bytes and fresh structures for exact text.

`structure-index.json` pins each stored and reconstructed structure. Observed JSON/XML schemas enumerate actual paths/types, including nulls. These schemas come from complete responses, not from client constructor extrapolation. XML empty IDs, duplicate IDs, result groups, choices, administrative fields and unrelated source content are retained literally; parsing them does not authorize summing overlapping group scopes. XLSX structure retention does not claim an application render or recalculation.

## Frozen source coverage

`immutable-inputs.json` identifies exact whole source files by state-relative path, length and SHA, plus all 196 historical virtual body resolvers. Historical old-path plus old-SHA references reconstruct from their captured gzip or immutable primary body. A repaired current file with a different hash is never substituted. `replay.py` reads all 31 frozen contract root fields, all 68 complete companions, all 403,993 ordered recursive objects across three full ledgers, producer manifests/owned bodies/originals and historical capture bodies without producer imports or writers. It retains all candidate/header/party/null/mask/method/admin/parent/control/raw-position schemas through immutable full-body references. No vote-only projection replaces a companion or original. Source-preparation and optional map/current/coordinator reviews are not build dependencies.

`parents/<FIPS>.json` has each complete frozen county context, all historical child keys, the complete actual SOS clerk directory block (including blanks and source disagreements), local request receipts and literal election links, individual findings, and the explicit primary county/native response investigation. FIPS is a county context key only. It proves no native identity across sources or years. Current county canvass-board designation is null when no actual local designation was proved; the statutory commissioners/registration-board alternatives are described separately.

`shared-parent-investigations.jsonl.gz` contains exactly 2,201 complete records in the external authorized coverage sequence. Each retains the complete frozen constituent object, exact original CSV header/party rows and full raw row, original receipt, frozen full-contract pin, immutable full-parent pin and all finer/current identity gaps. It includes all 33 `Voter Privacy` administrative observations and all 20 masked-candidate observations. These are **shared-parent investigations, not 2,201 discovered live feeds**, not certified vote ranks and not current geographic joins. Numeric labels remain labels. Physical precinct, method/early/absentee/central, reporting, choice and geometry joins remain null.

The sole declared county spelling association is results `Dona Ana` to directory `Doña Ana`, for parent context. Every source string remains unchanged. The canonical certified native full order/top15/minimum80 remain null and ordered priority keys empty. The compatibility CSV has one state row plus all 33 county parents, in authorized parent coverage order, with explicit blanks for unproved current fields.

## Validation and clocks

`check_samples.py` decodes all actual response bodies independently, closes complete primary county candidate totals to the state CSV, verifies directly exposed method sums, inventories every bounded native response and missing/masked fields, preserves general candidate status rows and full headers, tests the actual empty XLSX scope, and checks Bernalillo/San Juan raw-versus-client differences. `check_historical.py` independently rereads all four complete historical native CSVs and fresh Poppler output from original PDFs, checking all 495 county/candidate PDF cells and state totals. It never infers a protected number from residuals. `negative_fixtures.py` tests substantive rejection cases using those actual sources and mutated coverage/field/clock assertions.

Publisher time, publisher timezone, HTTP Date/Last-Modified and UTC observation are distinct. Source `MT` is retained as printed; clocks without zones remain timezone-unknown. San Juan's client formats HTTP Last-Modified in America/Denver; that does not make the jurisdiction timestamp UTC or a measured count-update time. Auto-refresh plans and completion counters establish neither measured cadence nor exact remaining eligible votes.

`extract_law.py` recreates whole texts from all retained selected PDFs and complete selected code sections, including annotations/history. `visual-scope.json` names exactly seven manually inspected rendered pages. Other pages received automatic text/hash/control checks, not manual visual review. Browser inspection was unavailable (no browser providers); web-tool failures are separate extracted observations, not complete raw bodies.

Run `PYTHONDONTWRITEBYTECODE=1 python3 -B senate/2026/new-mexico/data/results-sources/run_offline.py` from the checkout root. Then run the same command with `--audit` for read-only verification. The acyclic manifest includes every owned file, report, validation, final seal and proof except itself. Neither validation nor final seal reverse-pins the current manifest. Network acquisition is separate and changes the source snapshot; it is never invoked by offline replay.
