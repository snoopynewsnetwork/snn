# Wyoming regional newsroom access check

Complete current responses were acquired for
[Sheridan Media](https://sheridanmedia.com/),
[Jackson Hole News&Guide](https://www.jhnewsandguide.com/),
[K2 Radio](https://k2radio.com/) and
[Wyoming News Now](https://www.wyomingnewsnow.tv/).
Jackson's actual home navigation links a
[General Election section](https://www.jhnewsandguide.com/special/general_election/),
which also returned200. These bounded home/category observations establish
regional access; they do not establish a complete November Senate numeric
feed, supplier, live coverage or release cadence.

Sheridan's `Results 10/12/26` link and a poll-results action were not treated
as election counts or invoked as application actions. Wyoming News Now's
Wisconsin election-mail headline is another state's news. No filename, heading,
home date or section title admits a Wyoming result universe. Earlier Powell
and other regional access gaps are not cleared by a different publisher's200.

Five complete request receipts/whole response entities, literal election links
and source bodies are retained with raw/stored hashes. No paid article, account,
message, media crawler or guessed numeric endpoint was used.
`review.py` rechecks exact original bodies and the literal Jackson chain;
the full manifest excludes only itself. Read-only replay:
`PYTHONDONTWRITEBYTECODE=1 python3 -B -S review.py`.
