# Coordinator audit snapshots

These are byte-exact dated inputs, failed coordinator prototypes where
explicitly named, source-page renders and bounded audit outputs. Frozen report
copies retain their original bytes and relative-link context: open the original
report at the state root for navigation. The integration checker verifies those
exact report bytes and resolves links at their original locations. Producer
report-template links likewise refer to the generated state-root report.

Every acceptance remains an external path-only historical qualification. These
audit snapshots do not approve a current reporting, candidate, physical map or
legal crosswalk. Corrected prototypes and initial receipts remain distinct from
the final named pass artifacts; no older failure is represented as accepted.
