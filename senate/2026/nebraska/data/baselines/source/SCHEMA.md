# Nebraska baseline schema and reproduction contract

Version `NE-baselines-v1`, 2026-10-19. Numeric source evidence is independently parsed from original PDF/BIFF/HTML/CSV bytes; peer and coordinator derivatives are never numerical extraction inputs. Original source receipts preserve requested/final URL, UTC retrieval, HTTP status/headers/available redirects, source clocks/status and raw/stored bytes/hashes. Missing source metadata stays missing. A `.html.gz` news filename can contain a complete PDF or BIFF entity: gzip-decompress it and verify the raw hash; the suffix is not a MIME declaration.

## Source retention and coordinates

- `reused-originals.json`: exact read-only news original references and original receipts. Verify each raw and stored hash individually. Its aggregate-ledger hash describes the observed vintage, not a promise that the coordinator's growing ledger never changes.
- `extra-original-references.json`: seven additional full county PDF references. `acquisition.json`: this worker's successful primary refreshes and exact public linked-document receipts. Matching original bytes are referenced, not duplicated. `census-original-reference.json` pins and independently parses the official Census county-code original; Madison **31119**, McPherson **31117**. - Original canvass PDF pages/text: `extracts/canvass-*-pages.jsonl.gz`. Selected raw table rows retain source page, line, starting character column, complete line and candidate-column order. All unrelated content remains in complete original bytes.
- HTML contexts preserve original header/child markup, cells/attributes, nullable counts, hidden native ID, row IDs, source clock and completeness. Keys are `NE:2024-special:html:{literal county publication ID}:{literal native ID}`. Literal `_TOT` observations are administrative, not county control totals. County IDs such as 01 are not FIPS. Truncated rows are not zero-filled.
- BIFF original rows preserve **all selected-sheet cell values and types**, including the total footer, header and 95 formatted blank trailing 2020 rows. Context pointers are sheet plus **one-based** row. Key `NE:2024-special:douglas-biff:{literal Ward-Precinct}` does not assert equivalence to ENR native IDs. Native counts combine early/polling votes per workbook instructions. `ballot_reconstruction` is total votes + over + under, not asserted observed ballots.

- Scan pages are independently rendered from full originals. Matching peer PNGs are reused only after identical independently rendered PNG bytes/hashes. OCR is a reading aid. `scan-manual-repairs.json` records explicit source-image transcription repairs; no missing number is allocated from residuals. Selected complete pages were visually read. Garfield attachments are retained as distinct non-Senate contexts, Deuel is unofficial and blank methods stay null. Scan and text PDF contexts are alternate observations, not additions to the disjoint HTML/native partition.
- Public CSV rows retain the 15-field header and each exact 16th unheaded empty cell. CandidateID/PartyCode/clock/counters are historical-publication scoped; never current mappings. Statewide and congressional district presidential elector tables overlap.

## Historical target schema

`settings.json` is authoritative for report settings: low2022, base2024, high2020 actual county Total Voting mixes multiplied by each county's observed2024special named-pair participation. Native sensitivity scales each2024 unit within its county by those hypothetical county totals, **not a cross-year native join**. Five separate preference anchors plus each anchor's actual historical own-pair weights yield **46** statewide target outputs and **11,676** unit rows. Native preferences are statewide-complete only for the special. Missing native comparator preferences are not filled from county values.

`scenarios/unit-targets.jsonl.gz` contains every county/native row for each relevant run: source anchor A/B; historical share q; declared pair volume T; normalized weight; baseline/target net contribution; target share/margin; target gain; share/margin changes in points; net value of +1 share point before/after clipping; requested versus clipped q; unbounded target; clipping flags; selected-unit-only unbounded/display share, status, explicit other-unit baseline net and assumptions. All units, including nonpriority, enter each statewide sum. `unit-contributions.csv` is a compact base special county/native slice. `state-targets.csv/json` retain volume, baseline net, signed unbounded/bounded shift, clipping count and achieved net.

Fractions are internal; share percentage points =100×share change, pair-margin points =200×share change. Net votes are counts, not points. Unbounded shift for target margin m is `(m*T-M)/(2*T)`. m=.01 is A+1 pair margin; .005 additional share is +0.5 share points. Bounded solution uses `clip(q+delta,0,1)` and solves the monotone statewide equation. Signed negative shifts/already-A-leading status are preserved. Selected-alone q is `(m*T-M_other+T_unit)/(2*T_unit)`, with every other unit fixed at that run's baseline q,T. Values outside[0,1] remain in the unbounded field; the display clips without declaring the target achieved. Zero pool and unknown anchors have explicit statuses.

All-candidate cushions use a distinct denominator. For the special actual all-candidate denominator, participation and all-candidate cushion are null: the published two-named denominator is not upgraded to eligible all-candidate scope. Other anchors' printed complete columns include separately identified scattering. Their denominator-conversion cushion explicitly assumes held historical participation, without asserting generic marks are eligible named votes.

`current-five-choice.json` has **54** explicit conditional paths and the companion compressed file **27,216** unit rows. Current identities derive from the final2026 primary publication, not nominees, setup IDs or historical opposition labels. Three other choices are preserved individually; each run states its assumed shares, denominator and optional zero eligible-write-in assumption. Every transported historical preference is explicit and unevaluated. Pair ties/A+1 and all-candidate A+1 are separate; unique highest five-choice totals and a legal candidate-by-candidate boundary are assessed. A 55% third-choice stress case shows pair success can lose. All are arithmetic, not calibrated probabilities.

## Live calculator

`calculator.py live INPUT.json` requires counted_A, counted_B and a dictionary of every named counted_others (actual final known choices plus any eligible named write-ins supplied by operator). Counted values remain fixed. `remaining_pair` is only the stated remaining A/B pool, not final turnout; `remaining_others` gives separate additions for each named other, with exactly matching keys. Null is unknown, negative is invalid, zero is no positive pool. Optional remaining_A_share is explicitly clipped and reported; null yields thresholds only. No implied missing zero. Counted corrections require a new observed input, never a fitted counted shift.

Final pair denominator = counted_A+counted_B+remaining_pair. Final all-candidate denominator adds all counted/remaining other votes. Final pair A+1 uses .01×final pair; final all-candidate A+1 uses .01×full final denominator. `remaining_units` supports selected-unit-only remainder thresholds with other units fixed at explicit pools/shares. Unknown other pools leave the all-candidate/plurality outcome unknown. Strict integer minimum A remainder votes beats B and every other candidate individually; ties are identified separately. **16 saved live scenarios** and **7 static target edge cases** exercise secured/impossible/unknown/no-pool/negative/clipping behavior. Outputs have probability null, not a calibration claim.

The existing external `/tmp/snn-xls-reading-libs` may be used; nothing is vendored. No dependency/cache directories belong in deliverables.

Run `python3 -B senate/2026/nebraska/data/baselines/reproduce.py` from root for original extraction, both peer audits, scan parsing from retained independent OCR and explicit repairs, universe, calculations, report, validator and asset audit. Scan rendering/OCR itself is reproducible with `extra_controls.py` (full original bytes required); no network is needed. `acquire.py --fetch` and `--linked-documents` are optional public refreshes and retain receipts; reproduction does not download. The existing coordinator preflight was independently executed with its output directory redirected into this owned source directory, not the shared tree; `preflight-reproduction.json` records exact comparison.

`validation.json` is meaningful invariant output, not a generic pass placeholder. `asset-manifest.json` covers every owned report/CSV/data/script and required reused raw/derivative reference by exact bytes/hashes, excluding only itself to avoid recursive hashes. Validate it with `validate.py --check-manifest`; each stored asset is strictly below40,000,000 bytes. Full originals use lossless gzip with raw hash after decompression; none is truncated or simplified. The known1MiB historical truncations remain explicitly labeled as incomplete observations. Shared news ledger grows; use individual source pins, never require its aggregate to stay fixed.
