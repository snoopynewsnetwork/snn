# Nebraska map evidence and reproduction

This package uses external historical authority at `../data/coordinator-priority-acceptance.json` **by path only**. The frozen contract remains at `../data/turnout/priority-set.json` (3,889,923 bytes, SHA256 `125fef1c2e13ff4e0464ac5e75e82ec54c9ea5e675b42da7586c4ccfd90d5891`). No worker acceptance or current-geography flag is changed. This package supplies research assets and exact historical dispatch, not self-acceptance.

`index.json` contains the exact 765 priority, 1,326 full and 561 remainder order arrays, all 93 full/priority child maps and the child-to-parent map. `inventory` has exactly one map dispatch record per preferred observation. Every record has a byte-pinned complete recursive `/constituents/i` reference, shared acquired map assets, and a specific source/position/label/method/access/vintage gap. Four match fields are **null**, never fabricated equivalences. `named_votes_display_only` aids navigation; all original candidate/method/ballot/registration/status/source/null fields remain in the complete frozen object, not projected into this display column. `separate_nonadditive_objects` references all complete 329 administrative/partial objects, 14 alternate PDF contexts, two resident Senate-unavailable cases and two school attachments. Their fields and reference graphs survive unchanged through the complete contract root and every field's canonical semantic hash in `frozen-references.json`.

`parents.json` has all 93 parents, including the 35 without selected observations. Each contains both child lists, named counts, exact contract pointer, Census native source positions, qualified PDF/native service assets, individual access receipts and precise gaps. Census county selection uses only source `COUNTYFP20` attributes. It never pairs a VTD to a historical reporting observation. County identifiers use Census FIPS; historical HTML county/precinct IDs are publication local. Madison31119 and McPherson31117 remain distinct.

`receipts/*.json` retains exact requested/final URLs, redirects with status/headers, request method, retrieval UTC, source linkage/config pointers, complete response headers/status and original entity bytes/SHA256. `raw/*` retains complete entity or transport-error text; errors are not documents. PDFs are stored as identity bytes; other entities use deterministic gzip. For a split gzip artifact, concatenate pieces in receipt order before decompressing. Every stored file must be strictly below40,000,000 bytes. Wire Content-Encoding/Content-Length are retained in headers; requests decoded content is the entity being hashed. No wire-packet claim is made. Request time and source/HTTP dates are different clocks; unset publisher timezone/status/effective date remains unknown. Exact sent request-header dumps were not separately captured; explicit research headers and requests defaults are reproducible from `acquire.py`.

`source-references.json` pins the immutable 38-observation preparation snapshot and its complete original/error bodies. They are reused read-only without duplicating large originals or depending on the mutable preparation journal. `frozen-references.json` independently traverses the acceptance-listed frozen reports, reviews, manifests, validations and reciprocal proofs. Every complete contract field has an exact-byte root, JSON pointer, canonical recursive semantic hash and node count. Referenced JSON/JSON.gz pins recurse by path. Historical `data/news/manifest.json` is an opaque provenance edge embedded in a frozen producer file, not a rebuild dependency: its initial pin was independently checked; complete individual receipts and bodies remain referenced independently. No current newsroom aggregate is required. The six later receipts/239 total are optional news evidence, not map build inputs.

`native/*.json.gz` contains parsed derivatives alongside pinned original lexical JSON pages or SHP ZIP. Native services preserve every returned attribute, null, ring/curve object and dimension; IDs identify only the publication. Service schema and returned-page field lists are retained separately: Adams metadata `SHAPE_Area` returns `Shape_Area`, and a metadata geometry field is not an attribute. Neither is renamed or filled. Requests use all attributes, native geometry, Z/M/true curves, and no output CRS, precision, quantization, offset or simplification. Geometry-free count/allID requests precede and follow pages of at most50 literal observed IDs. Response errors, transfer limits, allIDs, counts and entire pre/post metadata are tested. Missing edit metadata stays null; equality of exposed metadata cannot establish unexposed concurrent edit absence.

The Census ZIP retains **all original members**, CRCs, DBF bytes and descriptors, SHP XY positions/parts/bboxes/record numbers and SHX offsets. Independent struct decoding verifies every point/part against installed PyShp3.1.6, whose Reader/Shape signatures are recorded. The adapter uses explicit `shp=`, `shx=`, `dbf=`, `cpg=` binary streams and never constructs a Shape with incompatible positional arguments. No ring closure, hole, coordinate or shape repair is written. `binary_shape` preserves original ordered parts/points/bbox; `geometry.rings` is an exact part slicing convenience. `counties/*` are complete county slices of that same source, retaining statewide source positions and all attributes.

`qa/*-native.json` separates native ring/position counts, null/empty/open/short/curve diagnostics, unrepaired validity and pairwise positive-area intersections. Diagnostic polygon construction uses exactly closed source rings and documented ESRI winding; counterclockwise rings are assigned to the smallest covering clockwise shell, with orphan rings reported. Invalid/unconstructible objects remain in originals and inventory; overlap tests use valid diagnostic polygons only. All native positions are checked finite. No geographic buffer, rounding, snapping or repair is applied. Douglas and Scotts Bluff areas use square US survey feet; Adams sphere-Mercator and Lancaster/Sarpy Web Mercator use square projected metres; Census uses square NAD83 degrees. Tiny positive intersections are reported without suppressing them by an arbitrary tolerance. No same-vintage legal outline was acquired, so gap/overlap **certification is false**.

`previews/*.svg` are display derivatives: source axes are fitted with a uniform scale and inverted Y into a1000x740 SVG, with positions rounded to0.001 SVG units and even-odd fill. They preserve every source ring vertex in the display path but do not claim original coordinate precision or suitable area/distance measurement. `Z` is a display closure; original rings were independently checked closed first. Native curve features would be retained and excluded from linear preview/topology rather than flattened. No curves were returned in these five snapshots. `previews/pdf/*.png` are complete uncropped original pages rendered by Poppler at maximum dimension1600, without cleanup. PDF text/metadata and page dimensions are in `qa/pdf-structure.json`. Printed date, file creation/modification, upload route, HTTP date, catalog edit time and retrieval date are never equated.

`index.html` is a static offline index with all 765 ordered entries, parent atlas and links to originals/receipts/complete objects. Its optional search hides rows without changing order. It uses no external scripts, fonts, basemaps or network requests. No browser surface was available in the CUA inventory (browsers=[]); HTML/link/JS-structure/SVG/PDF checks and inspected static renders are explicitly distinct from an actual browser-render test.

## Reproduction

Run from the repository root with Python3, requests, PyShp3.1.6, Shapely, PyMuPDF, Poppler and librsvg installed. No dependency/cache directory belongs in this package. Set `PYTHONDONTWRITEBYTECODE=1`.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/nebraska/maps/frozen.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/nebraska/maps/native.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/nebraska/maps/render.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/nebraska/maps/build.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/nebraska/maps/validate.py
```

These are offline operations. `validate.py` is read-only unless `--record` explicitly records its deterministic validation result within `maps/`. Native replay compares every regenerated geometry/attribute/SVG/check artifact with the existing file in memory, rather than trusting stored checks. `audit_assets.py` regenerates full owned membership, sizes and hashes (only its own manifest is excluded). `validation.json` is included in the manifest and never pins the manifest, avoiding a cycle. The coordinator externally pins the final manifest; worker self-acceptance is not introduced.

Acquisition is bounded and optional for replay. All explicit original request queues are retained as `*-requests.json` (plus `scotts-webmap-request.json`). `acquire.py QUEUE` reuses existing receipts and fetches only unobserved explicit IDs in that queue. To observe a new snapshot, use a new receipt ID/output destination; do not overwrite earlier observations. Parent acquisition starts with the actual SOS directory, and `discover.py` derives the exact58 literal priority-parent URLs. `service_requests.py seeds/pages/post` derives native queues only from acquired webmaps/allIDs. Other queues retain actual literal source links or observed official search routes. Public ArcGIS item/data and query constructors are documented and use observed IDs. No guessed API/layer/contest IDs are permitted. One accidentally queued unobserved Sarpy page number failed DNS before HTTP and is explicitly excluded from the source graph; its complete error is retained, never used for coverage or discovery.

For a shared original, reconstruct to a temporary path without changing shared files:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/nebraska/maps/reconstruct.py census-nebraska-vtd20 /tmp/nebraska-vtd20.zip
```

Every response remains original evidence; reproduction does not promise that a future server response will match a historical snapshot. No implemented collector, measured unobserved cadence, current crosswalk approval, future crosswalk exhaustion requirement or calibrated election forecast is claimed.
