# Virginia official-source evidence schema

The external acceptance authority is `data/coordinator-priority-acceptance.json`, resolved from the Virginia state directory. It is referenced by path only. Its body, digest and reverse pin are not owned assets. The turnout contract and historical bodies remain external read-only inputs; their exact body pins and complete-context pointers are retained where needed. No producer acceptance flag is changed.

`requests/*.json` is one actual immutable request observation. `requested_url`, `request_method`, `submitted_fields`, exact `submitted_body`, explicit request headers, UTC start/completion, and `public_parent_edge` describe the request. Each ordered hop retains actual requested/response URL, method/body/headers, response status, every response-header pair including duplicates, UTC retrieval/completion and its complete body reference. Redirect bodies and failures are retained separately. A transport failure without headers/body explicitly says so; no unavailable network metadata is reconstructed. This is application HTTP entity evidence, not a wire/TLS capture. Read-only directory POSTs contain only the observed `LocalityUid`; no personal input or messages.

The earliest 28 GET receipts omit the later-added optional `submitted_fields` property; their explicit `submitted_body:null` and GET method remain exact. The first pre-seal audit incorrectly required that optional property on those earlier receipts. Its failing traceback and implementation are retained, and the check now distinguishes those existing GET receipts from required POST field/body evidence. No receipt was backfilled.

`bodies/<raw SHA-256>.gz` stores one complete original response entity per raw hash, compressed losslessly with gzip mtime zero. References contain raw/stored sizes and SHA-256 values. Bodies are never truncated or reduced to a JSON projection; errors, HTML shells, zero-length entities and invalid/non-JSON content remain literal. No stored file reaches 40,000,000 bytes. The acquisition index inventories every receipt and all distinct originals. Search-tool snapshots under `discovery/` are separate discovery text, with no fabricated HTTP headers or original-response claim.

Complete JSON references contain the original response entity, request key and RFC 6901 pointer. The original body is the complete source context; pointer resolution is not a substitute for retaining it. Complete historical context references resolve a pinned frozen contract body and pointer plus full recursively canonicalized semantic SHA-256. Canonical JSON uses UTF-8, unescaped Unicode, sorted object keys, compact separators, finite values and preserved array order. Strict parsing rejects duplicate keys and nonfinite numbers. The sole explicitly frozen duplicate-key negative fixture is raw-pinned and independently reproduced using its authority-defined semantic view; it never becomes an admitted current source.

`parent-investigations.json` has all 133 parents in frozen inventory order, separate counties/independent cities, complete parent context, exact full/priority/remainder child arrays, source-specific contact/role rows, raw HTML field fragments, links, literal blanks and all actual directory attempts. Covington's missing state response stays unavailable; local pages and FVAP objects do not fill its board-role cells. The 134-record federal directory is a distinct administrative source and preserves its full original objects/effective-date fields. County/city FIPS association is parent inventory context only.

Each parent records the actual current state parent and whole current locality Senate body, observed setup IDs, full native/method counts, virtual count, source status/clocks and local authority requests. Whole bodies retain candidate/party/group/status/control/administrative fields, nulls, localized arrays and source order. Local HTML snippets are explicitly bounded observations, with complete raw pages and all links separately retained. A link to ELECT is overlapping upstream publication, not an independent vote feed. Failed and excluded older discovery chains remain history.

`full-native-hierarchy.jsonl.gz` contains exactly 2,669 ordered historical investigations. `priority-investigations.jsonl.gz` is its exact first 1,538 records and `remainder-investigations.jsonl.gz` its exact remaining 1,131. Every record resolves the full frozen native context and shared parent review. `source_rank` is one-based; source CSV logical positions include headers. Repeated Absentee/Provisional/virtual labels keep distinct source keys. Null current leaf/method/geometry fields express unapproved/unavailable matches, never zero or a physical-site join. `current-native-inventory.jsonl.gz` separately resolves all 2,528 whole current setup objects. The source CSV has the entire header and all 133 rows in inventory order.

`source-schemas.json.gz` covers each distinct successfully parsed original JSON entity with complete field/type occurrence counts and every array length in traversal order. Wildcard array paths group schema positions; all actual values/array orders remain in whole original entities and semantic controls. The format inventory automatically decodes every PDF original and complete CSV products, preserving stderr/exit status, whole header, row count, width set and full ordered-cell hash. XLSX inspection preserves every package member name, worksheet/cell position, string, raw value and complete cell XML; package bytes retain formatting/styles, omitted cells and other XML. No formula recalculation or workbook edits occurred.

Full code sections retain every current/future version, source character spans, complete text and links. Complete original HTML remains authoritative for layout/markup. PDF automatic full text/metadata is distinct from actual manual page review, explicitly listed in `manual-review-scope.json`; Alexandria has a recorded text-encoding defect. PDF dates, HTTP/cache clocks, source timestamps and UTC retrieval are separate. Publisher schedules and unchanged setup repeats are not measured election-night cadence.

Admission is false for all actual observations. `admission.py` is a testable research guard, not a collector: same election/contest/authority/production flags, verified complete bodies, genuine release evidence and non-setup timing/counts are necessary. A synthetic positive guard control is labeled as such. The guards also reject duplicate cumulative keys and overlapping levels/snapshots. Nothing derives a remaining eligible pool from registration, reporting fractions, methods or ballotItemCount.

`history/` retains actual classifier and checker failures, earlier implementations/plans and findings. Frozen first-pair histories are independently resolved by exact original path plus digest through archive/reference storage; optional later peer/map/news files are not build dependencies. `historical-replay.json`, `negative-fixtures.json`, `reproduction.json` and `validation.json` have deliberately limited claims. `final-seal.json` hashes earlier proof/handoff targets; the final manifest hashes all owned files except itself. No target embeds the current manifest digest.
