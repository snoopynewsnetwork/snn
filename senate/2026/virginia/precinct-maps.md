# Virginia precinct maps and source geography

Actual official map originals are retained for **all 133 Virginia localities**,
including all **108 parents of the 1,538 priority historical source records**.
The [offline atlas](maps/index.html) preserves every complete historical source
object, all 1,131 remainder observations, original parent/child order, actual
download receipts, source geometry and vintage/access qualifications. This is
completed bounded map research for coordinator review. It establishes **zero
approved result-to-polygon joins** and makes no legal or live-data admission.

Research retrieval: **2026-10-20 UTC**. External historical authority is
[path only](data/coordinator-priority-acceptance.json). The
[independent own replay](maps/authority-replay.json) checks all 25 whole roots,
471 whole companions, 3,474,062 recursive objects, 24 ordered ledgers, 721 fixed
files, 1,172 exact historical bodies and both producer seals. No producer code
was executed and no unfinished official-results package was used.

## Vintage, geometry and manual scope

ELECT says locality-supplied boundaries are kept as current as possible and
warns that newly enacted changes may take weeks to appear. Published filename,
printed creation date, ZIP timestamp, XML creation date, DBF editing date,
effective date and adoption are separate concepts. The files do not establish
complete legal November geography. Current/legal approval stays false/unknown.

For example, the state Washington County and Accomack maps print March 30,
2026; Norfolk prints August 31, 2026. Alexandria's local map prints March 27,
2026 and describes a State Plane/feet mapping standard, while the downloaded
state shapefiles use Web Mercator/meters. A Fairfax Braddock description prints
December 2021 and its following map February 2022. The Mason book has a later
filename but its viewed Baileys map prints March 2025. Each distinction is
retained without inventing amendment precedence or legal approval.

[Native binary proofs](maps/binary-audit.json) cover all 134 actual ZIPs: 4,997
features, 5,093 parts and 4,783,111 XY positions, with both source inventories
separate. An independent binary reader checked full ZIP CRC/member contents,
DBF schema/raw cells/attributes, every SHX index/offset/length, SHP types/parts/
bbox and every XY double bit against installed PyShp. Its constructor was
inspected before use; no auto-closing adapter was used. All acquired shapes
are type 5, XY polygons. No native service snapshot, Z/M or truecurve claim is
made.

The separate [whole-original reconstruction](maps/original-reconstruction.json)
also verifies 166 complete source receipts, 170 whole response entities, nine
legacy originals, all 11,553 literal records in four historical contest CSVs,
every primary native API object, all 40,035 candidate/method constituents and
all 8,055 Senate bulk rows. Eight native source associations contain nine bulk
rows apiece, including the extra blank-ID zero records. Every constituent is
summed and retained; no exactly-three-row or overwrite assumption is applied.

Seven ELECT datasets contain a nonsimple source ring: Lunenburg, Pittsylvania,
Rockingham, Smyth, Washington, Lynchburg and Richmond City. Source geometry
remains intact. Repeated names, split features and unavailable labels also
remain. Signed ring areas and line simplicity are native-unit diagnostics,
not legal gap/overlap/sliver or ground-area certification. Atlas previews draw
every original position as unfilled part outlines, reflect Y only for display,
and perform no repair, simplification, ring classification or fabricated outline.

[Every PDF page](maps/pdf-pages.html) was automatically rendered, with complete
originals and full extracted text retained. **Exactly ten whole-page images
were actually viewed**, enumerated in [manual review](maps/manual-review.json):
Accomack, Washington, Norfolk and both Fairfax state pages, Alexandria's local map,
Braddock description/map, a Fairfax change-summary overview and Mason Baileys.
This is a selected-page visual review; no whole-book or all-parent manual
inspection is claimed. Small labels may require the retained original PDF.
Source accuracy/general-information warnings remain in the original and text.

## Reproduction and immutable handoff

Run these from the repository root:

```sh
python3 -B senate/2026/virginia/maps/replay_authority.py --check
python3 -B senate/2026/virginia/maps/audit_originals.py --check
python3 -B senate/2026/virginia/maps/audit_acquisition.py --check
python3 -B senate/2026/virginia/maps/validate.py --sealed
```

The [validation](maps/validation.json) reconstructs all native/decoded evidence,
PDF renders/text and atlas products from fixed individual inputs with networking
disabled, compares every byte, audits complete relative links and full-object
DOM contents, and executes the shipped filter against all 2,669 parsed source
datasets. [Negative fixtures](maps/negative-fixtures.json) reject missing source
objects/fields, wrong positions/nulls/counts/IDs/CRS, false vintage/legal/alias/
county-substitute claims, spatial allocation and unsupported service metadata.

The [final seal](maps/final-seal.json) precedes the
[complete owned manifest](maps/asset-manifest.json). The manifest excludes only
itself and includes this report, all histories, originals, scripts, proofs,
validation and seal. The final full read-only audit follows sealing; no owned
writes follow a passing audit. Coordinator acceptance and publication remain
external. Current legal geography, eligible write-ins, November feed IDs,
cadence, outstanding ballots, collectors and probability approval remain
false/unknown external qualifications and do not reopen this bounded research.
