# Virginia source map package

The external historical authority is **path only**:
`../data/coordinator-priority-acceptance.json`. It is neither copied nor hashed
by this package. `replay_authority.py` independently reconstructs its entire
ordered reference graph, all whole companions, exact historical archive members
and individual originals, and both frozen producer seals. It imports no producer
code and writes only its own report. Historical resolution requires the original
path **and SHA256**; a newer body at the same pathname is insufficient.

`input-pins.json` freezes individual acquired receipts/entities and the exact
historical contract. The state/local navigation snapshots describe actual source
anchors and selector fields; they are frozen acquisition context. No unfinished
official-results package, current peer helper, newsroom aggregate or producer
writer is a dependency. `sources.html` links complete individual originals and
all exact archive-member identities. Its original links work in the shared
offline checkout. Copying only `maps/` omits explicitly linked first-pair evidence.

## Source observations and geography

The primary source is the literal2024 Senate CSV, not a physical-precinct list.
There are2,669 source objects under133 distinct county-equivalent parents:
95counties and38independent cities. Descending exact reported candidate/generic
marks, then numeric logical CSVrecord, defines the native order. Priority1538
and remainder1131 are retained whole;108parents have priority children. The
separate44parent sensitivity is never a dispatch substitute. `parent-coverage.json`
keeps the full133inventory; `unit-coverage.json` keeps every native record's
qualification and source position in parent order. The contract's complete
global rank order and all133full child arrays are independently replayed.

Every parent HTML page contains its entire original parent and every entire
native object, in that parent's source-rank subsequence, in escaped JSON `pre`
elements. Nothing is reduced to vote totals. The original UUID, `isVirtual`,
mapFeatureId nulls, source records, raw CSV rows/cells/positions, all candidates,
parties, method/group IDs and all5method counts survive. All40,035whole method
constituents and48blank-ID export rows remain in complete linked source bodies.
Explicit null/blank/literalzero and missing observations stay distinct.

`current_candidate_feature_positions` is a **search aid only**: within the exact
parent, integer representations of a historical literal numeric code and current
SHP `PrecinctFI` agree. Full original labels and both IDs remain. No candidate is
admitted as a geographic, legal, physical, crossyear or November match. Virtual
records have no polygon assertion. No votes, ballots or registration are spatially
allocated. Source polygon counts, administrative result counts, split features,
duplicate names/codes, unmapped units and Census VTDs have separate scopes.

ELECT publishes current maps supplied by localities and warns of update lag.
Published filenames, printed map dates, PDF creation clocks, DBF editor/date
fields, ZIP timestamps and XML metadata are separate evidence. They do not
establish adopted/effective/legal November geography. `vintage` preserves those
distinctions, with adopted/effective/current approval unknown/false. Census2020
VTDs use their actual `STATEFP20`+`COUNTYFP20` county-equivalent partition, including
all38independent cities; they are historical fallback context, never current IDs.

## Acquisition and lossless reconstruction

`requests/*.json` records the actual public method, requested/final URL, source
parent edge, UTC clocks, explicitly supplied request headers, submitted read-only
locality lookup fields, status, complete ordered response-header pairs, redirect
entities, publisher/cache clocks, errors, raw bytes/hash and stored bytes/hash.
`originals/` stores each complete gzip entity once by hash, or ordered lossless
gzip parts, each strictly below40,000,000bytes. Reassemble **all** ordered parts
before gzip decompression. Full error bodies are retained; no-body DNS failures
have null status/body/header/hash fields. Initial failures and later successes
are separate receipts. No response is called complete after a read exception.

Request-header metadata records headers explicitly supplied to urllib. Its
automatically generated Host/Content-Length/Content-Type and transport framing
were not separately captured; there is no wire-header claim. Original initial
ad-hoc DNS probe timing was not captured; the repeat acquisition failure has a
full no-body receipt. `history/navigation-corrections.json` records a mistaken
unlinked404and a mislabeled initial selector probe; neither establishes a source
chain. `history/map-filter-correction.json` excludes accidentally acquired forms
and ballot samples from map claims. Those originals remain as acquisition history.
Directory403s/challenges stop that source, with no authentication or bypass.
No personal voter query, outreach or contact form was submitted.

Reconstruct a downloaded original outside the sealed package:

```sh
python3 -B senate/2026/virginia/maps/reconstruct.py state-pdf-51191 /private/tmp/washington.pdf
```

For an older original, use the exact path and SHA listed in `sources.html`:

```sh
python3 -B senate/2026/virginia/maps/reconstruct.py --historical ORIGINAL_PATH ORIGINAL_SHA256 /private/tmp/original-body
```

## Native binary geometry and previews

`binary-proof/` enumerates every ZIP member with full CRC32/hash/bytes and audits
every dataset. `decoded/*.json.gz` is an independently decoded SHP/DBF derivative,
**not** native ArcGIS service JSON or a newly downloaded SHP. Complete source
ZIPs retain their original SHP/SHX/DBF/PRJ/CPG/XML and other members. All source
field descriptors, DBF raw tokens, interpreted values/date types/deletion flags,
record positions, shape types, part indices, boxes and XY positions are retained.

The independent byte reader checks all ZIP CRCs and members, exact SHX indices,
offsets and lengths, complete SHP headers and records, every part/bbox and every
XY IEEE754 double bit against installed PyShp3.1.6. The installed constructor was
inspected first and retained in `history/pyshp-constructor-inspected.txt`. No
`lines=`adapter or ring-closing constructor is used. All acquired datasets are
SHPtype5(XY polygons): no Z/M/truecurve/service snapshot is claimed. No repair,
simplification, deduplication, implicit closure, precision reduction, outCRS or
orphan-hole reinterpretation is performed. Null geometries would remain literal.

`previews/*.svg` draw every source part and original position, with a display-only
Y reflection and native-coordinate viewBox. They use strokes with no fill, ring
classification, fabricated outer boundary or vote overlay. ELECT is native Web
Mercator; Census is its own native NAD83 geographic CRS. Ring simplicity and signed
native-coordinate areas are diagnostics only; source-invalid rings remain intact.
These are not ground-area, legal gap/overlap/sliver or topology certifications.
Source overlaps and split geometry remain unrepaired.

No service snapshot was acquired. Therefore service/layer pre/post metadata,
ALLIDs/counts,<=50IDpage disjoint unions, Z/M/truecurve preservation and service
change comparisons are **not claimed**. Native-service assertions without their
original evidence are rejected by the negative fixtures.

## PDF and offline audit

Every complete acquired PDF is retained losslessly. `pdf-audit.json` inventories
every document and page, full PDF metadata, full extracted page text and every
automated1400pixel full-page PNG. Original warnings and fine print survive in the
PDF and full text. `manual-review.json` names **exactly10wholepageimages actually
viewed**; all other pages have automated rendering only. This is not whole-book
manual review or legal approval. Incidental nonmap PDFs are explicitly excluded
from map coverage while retained in acquisition history.

`validate.py` disables networking; reaudits all originalZIPs, reconstructs all
decoded geometry/proofs/HTML/SVG/PNG/text in a temporary tree, compares every byte,
checks all original request parts and every relative HTML link, compares every
complete source object in the parsed HTMLDOM and executes the shipped JS filter
against all2669parsed DOM datasets. It tests all/priority/remainder, literal keys,
case handling and zero results; no unseen-browser claim is made. Negative tests
mutate actual complete objects/inventories and reject missing priority/admin/
wholecompanion/original/null/position/candidate fields, count/CRS/ID/vintage/legal/
alias/county-substitute/spatial-allocation errors and unsupported service claims.

Run `python3 -B senate/2026/virginia/maps/replay_authority.py --check`, then
`python3 -B senate/2026/virginia/maps/audit_originals.py --check` for the independent
whole-receipt/entity/CSV/API/method/export reconstruction, then
`python3 -B senate/2026/virginia/maps/validate.py --sealed` for the full network-free
audit. No producer code is executed and no owned writes occur in sealed mode.
`final-seal.json` precedes `asset-manifest.json`; the manifest contains every
owned file, including reports, histories, proofs, scripts, validation and seal,
excluding **only itself**. There is no reverse manifest digest cycle. Coordinator
acceptance/publication remains external.
