# Florida map evidence schema

This package contains archival research, with no running collector, reporting-unit crosswalk, method assignment, legal-outline certification, vote allocation or live forecast. `index.html` is static and offline. `inventory.json` has exactly22 ordered priority entries and45 explicit remainder entries, preserving all67 frozen parent objects. `manifest.csv` describes90 selected original map entities (including native GIS batches); `asset-manifest.json` inventories every owned file, excluding only itself. The separate Orange2024 acquisition remains available through its full batch index and ledger; it is not substituted for2026.

`frozen-contract.semantic.json.gz` is a complete JSON semantic copy of the pinned23,823,926-byte contract, preserving object insertion order, array order, every value/type/null/false flag and every other-contest/source/admin object. `frozen-reference.json` records the canonical SHA256, recursive object equality, complete input pins and the separate external historical acceptance. The frozen `coordinator_accepted:false` and Gulf's operational nulls remain unchanged. Neither acceptance nor geographic timezone scope grants current physical approval.

`identity-diagnostics.jsonl.gz` contains23,532 records. Each embeds the **complete** immutable `native-units.jsonl.gz` source record, including election/contest/native identity, candidate/category rows, votes, registration observations, original row positions and source flags. It also retains a full frozen-constituent JSON pointer/digest, source-line ordinal and digest. `physical_geometry_match`, `method_assignment` and `legal_named_writein_allocation` are null; `lexical_candidates` is empty. All records, including missing IDs, split/style/central/early/mail labels and unknown physical units, remain unallocated. No precinct-name, FIPS, numeric ID, count or method-label join is performed.

`raw/*.receipt.json` records original request/final URL, parent source ID, UTC start/end, request/response headers, redirects, HTTP/error status, entity encoding, original byte count/SHA256 and stored path/count/SHA256. HTTP200 is not accepted as map data without structural inspection. Error entities and200 HTML shells are preserved. For maps-worker fetches, `Accept-Encoding: identity` was requested; the archived entity is Requests-decoded HTTP content, not TLS/wire bytes. Shared coordinator references have null request headers/redirect chain/client encoding when absent from the supplied receipt; these fields are not inferred. The response Content-Encoding survives. Gzip usesmtime0. Exact duplicate entities reference one stored body. Successful small PDFs, ZIP/KMZ and official PNG are stored directly; other responses are losslessly gzipped. For files that cannot compress below40,000,000 bytes, acquisition supports ordered30,000,000-byte parts with original SHA/bytes and per-part SHA; no current asset required splitting. Every stored file is strictly below40,000,000 bytes.

`source-ledger.json` contains complete receipt objects, native editing/time-reference metadata and literal PDF metadata clocks. HTTP Date/Last-Modified, retrievalUTC, catalog modification, source feature dates, PDF creation/modification, printed revision/as-of and legal effective dates are different fields. Unzoned literals stay unzoned; null clocks remain unknown. ArcGIS epoch clocks are UTC instants where the source declares UTC; Volusia declares Eastern Standard Time with daylight saving. A label, filename, as-of date or later republishing clock is not an election-effective adoption or measured election-night cadence. Web-reader captures are separately labeled returned text; their file-written timestamp is not an HTTP retrieval clock.

`<county>.acquisition.json` documents an ArcGIS layer's exact source count, object-ID field, full pre/post ID requests and every bounded batch. All attributes, native CRS and server-exposed coordinate precision are retained in raw original JSON. Queries request geometry, Z, M and true curves, with nooutSR, geometryPrecision, quantization, maxAllowableOffset or simplification. This preserves the service export, not an unobserved database backup. Pre/post ID stability is checked; a nonversioned service can change geometry without changing IDs. Undefined Z/M metadata stays unknown. Schema fields, domains and source attributes remain in layer originals. Attribute-only/null/empty geometries are distinct from true-curve geometry.

`geometry/<source>.json` provides every feature locator, full source attributes, attribute/geometry digests, native XY vertex/ring counts, ordinate dimensions and each defect. It records all positive-area overlap pairs, exact XY-ring duplicate groups and per-field null/blank/duplicate values. Native axis units come from the service CRS or original PRJ. Diagnostic areas are in axis-units squared (degrees squared for geographic data), never automatically hectares or square metres. Containment-depth ring interpretation is for GEOS diagnostics only. No repair, snapping, orientation rewrite, deduplication or missing-polygon inference occurs. Curved features are excluded from linear GEOS diagnostics and explicitly counted. No external legal county outline was acquired or used for certification.

Original ZIP diagnostics check every member CRC/hash and the complete SHP/SHX record count, offsets, record lengths, DBF count, deletion flags, encoding and PRJ. Native archives remain intact; member metadata does not replace them. KMZ diagnostics retain every original folder and placemark via the archive, distinguishing precinct placemarks, polygon parts, polling points and other districts. KML ordinates/altitude modes and extended data remain in original XML. Google and Dolphmap display/export generalization and original county database precision are unknown. No current map ID is declared equivalent to a submitted original19-field identity.

`previews/*.svg` andPNG are research displays. SVG XY positions round to0.01 display pixels; native originals are unchanged. Volusia's linear preview explicitly omits31 curved features; its separate saved official server raster is the default preview. `pdf-render-validation.json` enumerates every original PDF page, dimensions, extraction/image counts, PNG hashes and source-render warnings. All89 pages of14 PDFs were rendered and contact sheets produced. PDF text is a derivative, not an original or numeric precinct dictionary. BrowserUI was unavailable; static PNG/PDF/SVG review and HTML structural/link checks are documented separately.

`peer-compatibility-reference.json` preserves the full coordinator source review and exact raw pins informationally. Protected/null Pinellas literals remain nonnumeric; Lake's separate dash1–29 banner is not transferred to Pinellas. Generic write-in counts, legally valid/named county totals and original19 submitted marks retain their different scopes. The original19 fields contain no method column. EAVS participation and bookclosing registrations are separate administrative snapshots. No masked value is replaced or allocated.
