# Reproduce Florida official-source research

The scripts are one-shot research/acquisition and offline validation tools, not a running election collector. Do not poll endpoints or infer live cadence from the captured client code.

Use Python 3 with `requests`, `beautifulsoup4` and `pypdf` in an environment **outside the repository**. Poppler is used only to render separate PDF previews. No dependency tree or cache belongs in this package.

1. Verify the frozen contract SHA-256 `0c056e0ebfdb393d4fcb59676805122d8442f444200b9edaf7f4c979c5e9a173` and read the external acceptance path. Read [first-pair pins](first-pair-pins.json); the final turnout/baseline manifests are immutable, read-only dependencies.
2. **Offline reproduction:** run `PYTHONDONTWRITEBYTECODE=1 /path/to/python parse.py`, then `build_package.py`, then `validate.py` from any working directory. The first two reproduce full source-scoped extracts/inventory; validation independently parses complete source originals. Retain the final report before validation. Normal validation writes its report and the exact asset manifest; `validate.py --check` verifies that manifest without rewriting it.
3. Acquisition, only when intentionally refreshing research: `acquire.py tasks-FILE.json` follows the exact saved tasks. Dependencies were inspected in order: directory → authority → results parent → BASE/iframe/year selector/client constructor → specific download. Each task stores the parent/source-link evidence. IDs cannot be substituted for November based on an older route. Existing IDs are skipped only when their URLs agree; duplicate task IDs are rejected. New observations require new IDs. A new nonce may be necessary for Orange's public pagination and must be read from a newly captured parent.
4. `prepare.py` reproduces the authority tasks and complete frozen-context semantic copy. Its 67 actual authority links come from retained original DOS countyInfo HTML. It does not create an approved current reporting crosswalk. `build_package.py` carries whole native objects in global source order and full original metadata; it does not allocate native or administrative counts.

The ordered task files document actual adaptive requests. Browser-reader observations are retained separately as `web-*.txt/json`; these are tool rendering/search evidence, **not complete HTTP originals**, and do not substitute for own retained 403/error entities. Some older web captures are JSON strings containing the complete tool response. A search result alone does not establish a vendor's authority. Current CivicPlus recovery uses actual linked institutional alternate hosts; main-domain errors remain.

Acquisition corrections: an early dependency probe lacked BeautifulSoup; dependencies were installed externally. Duplicate task IDs in a docket's two-link rows were caught/repaired with unique link IDs, and all affected complete entities were reacquired. The final guard rejects such collisions. A prior wrong-range `98.0981` request returned a 200 generic statute page and remains a non-data/error observation; `law-98.0981-correct` is the actual statute. Publicly linked Lake county/election JavaScript assets returned 404. No 200 shell or generic page is admitted as data.

All raw response bodies are complete and gzip-compressed or referenced by exact immutable hash. Restore a body using the `body_path` and storage description in its receipt. For shared historical ZIPs, use `shared-evidence.json` → `original_references` → `relative_path` relative to `data/turnout/source/`, decompress once, then check raw SHA-256/bytes and all ZIP CRCs. Overlapping recount members remain in the originals but are excluded from the selected base contexts, never added twice.

No live November sequence was acquired. Static comparisons cannot demonstrate first/second/recount transitions, corrections, publisher lag, change bounds or measurement cadence. Retain competing scopes; do not convert masked/protected values to zero or redistribute generic write-in marks to valid named candidates. All 45 remainder counties remain in statewide arithmetic even where discovery is shallower.
