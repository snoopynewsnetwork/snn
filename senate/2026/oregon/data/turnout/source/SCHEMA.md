# Oregon turnout source and calculation schema

Research snapshot: 2026-10-20. All current-election, source acceptance and geometry approval flags remain false. No peer was launched when this independent witness was prepared.

## Authority and retained bytes

`shared-original-pins.json` pins read-only originals in `../../news/`: requested/final URLs, UTC retrieval, HTTP status, headers, redirects, raw/stored hashes and ordered gzip byteparts. `original-inventory.json` independently hashes all 72 original ZIP members, their literal archive paths, ordinals, CRCs and sizes. The original ZIPs are stored once by the coordinator. `../../audit_precinct_archives.py` restores their ordered gzip stream and verifies original ZIP hash/CRC. Importing its `restore` function performs no coordinator writes. Never run its writing `main` as part of this worker's rebuild.

2024 abstract: complete 1,185,360-byte December 12 capture. The January 18 1,048,576-byte capture is a prefix, not a new count vintage. 2020 abstract: record 13735450 DocumentStream, 588,518 bytes. 2022 abstract: record 13735454, three contiguous retained Content-Range entities reconstruct 462,872 bytes. Partial HTTP 500 PDF prefixes are not complete originals. Wasco 2024: record 10575034, 525,495 complete bytes. No guessed record IDs, calendar, live result ID or geometry follows from these archival labels.

Owned `acquired/*.receipt.json` retains each new request's exact URL/parent chain, each response entity and redirect, headers, retrieval clocks, original entity hash/bytes and deterministic gzip hash/bytes. Error responses are complete HTTP entities where received; initial sandbox DNS failures produced no HTTP entity and remain explicit local errors. Requests removes HTTP Content-Encoding before exposing an entity; the retained PDF/CSV entity itself is byte-exact. HTML errors are not counts. `pdf-text-inventory.json` checks signature/EOF and extracted page count for owned PDFs. New current participation URLs returned 404; actual CDX-listed archived originals supplied complete 2020/2022/2024 statistical summaries. The 2024 statistical PDF is 49 complete pages; only the required county total participation page is tabulated. Its unrelated demographic pages remain in original bytes.

Every stored artifact is strictly below 40,000,000 bytes. Raw historical ZIPs must be restored temporarily outside the repository. Members are referenced by ZIP/member hashes and source positions, never duplicated en masse.

## County control tables

`county-candidates.csv` contains all 864 selected original county candidate/Misc. positions: 36 × (8+5+5+6). `candidate_key` is contest plus source column ordinal, not a deduplicated person key. `source_header_literal` joins printed header lines with `/`; `raw_line`, PDF page and one-based layout text line preserve the row. Names and party labels remain those printed in that specific abstract. Every column sums to its printed footer in `statewide-footers.json`.

`Misc.` is a reported generic scope, not proven legally valid named write-ins. Named-candidate-only totals exclude that column; reported totals include it. Blank/nonvote fields are not candidates. No missing candidate cell is filled with zero. The 2024 vice-president table has six printed columns, not eight: Shanahan, ter Maat, Vance, Ware, Walz, Misc. `nonadditive-vice-president.csv` preserves every row and its exact overlapping presidential column. West and Terry have no vice-president column in that table; none is invented. Never add this presentation to president.

`participation-controls.csv` preserves each statistical summary's **Number Eligible** and **Ballots Returned** total columns, source page/line, and literal row. These are separate from canvass ballots cast and the monthly registration comparison snapshots in `monthly-registration.csv`. No all-county canvass ballots-cast series is inferred from statistical returns. Monthly report dates/status definitions are not silently made election-day denominators. The current historical-turnout PDF's 2020 total conflicts with the election-specific statistical summary and remains separately qualified.

`../county-turnout.csv` is a compatibility filename for **36 county parent sensitivities**. It is not the canonical reporting-geography dispatch. Full county orders for every contest/named scope/participation measure, top-15 fractions, preceding counts/votes, crossing rows and remainders are in `county-sensitivities.json`.

## Native observations and overlapping methods

`native/observations.jsonl.gz` retains source key, county/FIPS, literal native unit, source row/page/line or CSV record, literal candidate/control label, integer and method. Raw CSV dictionaries preserve every column in selected contest rows, including native Contest ID/Choice Order and choice-specific counters. `native/units.json` is a working normalization of observations, including incomplete OCR groups. Its `additive` flag describes source hierarchy, **not acceptance of an unreconciled number**. Read `native/county-reconciliation.json` before any arithmetic. Unclosed groups and uncertain OCR counts are not approved input. `extraction-issues.json` preserves conflicts, missing columns and parser gaps; it is not a list of source corrections.

Original PDF text and source-positioned OCR are retained. `ocr/` is a first-pass locator derivative. `refined-ocr/` retains higher-resolution TSV word boxes, text and engine metadata. Neither replaces the original raster. `visual-row-transcriptions.json` records exact Washington source page/line and direct visual integer readings; unchanged OCR remains alongside it. The first Wasco 2024 certification page was directly inspected: its presidential Write-in is 5; its 1,831 presidential ballots differ from some other offices' 1,830. A missing OCR glyph was transcribed from the original, not allocated from a residual. Selected source raster QA is in `qa/`.

2024 known-source ranking uses exactly five disjoint county child sets: Multnomah SOVC2 (107), Washington (155), Clackamas (118), Marion (118), Wasco (12). In Multnomah, all 107 literal numeric CSV precincts independently match all eight values in the county's PDF `Precinct N` rows. The PDF supplies separate registration/ballot/nonvote fields. Native contest ID 39 and choice-order values belong to that 2024 source only. The summary SOVC1 and PDF are overlapping presentations, not additional votes. CSV `Overvoted WithVote for this Choice` is candidate-specific and is not a contest overvote-ballot count; `Ballots WithVotes for Others`, repeated undervote/ballot fields and Double Voted counters retain their original scope.

Clackamas's 115/116 is one combined source row with both literal constituent IDs and no allocation. Its 119 reported precincts and 118 disjoint rows are retained separately. Explicit zero rows remain. Bare summary `Totals` rows are nonadditive. Marion's Cast Votes includes its generic write-in; Clackamas's Cast Votes excludes its separate Miscellaneous Write-In column. Washington's presidential precinct-table ballots sum to **301,104**, matching its table footer; the overall report header says **301,105**. Its presidential 297,949 choices + 170 overvotes + 2,985 undervotes equals 301,104. No one-ballot residual is assigned. Wasco AB/ED/EV, Marion Absentee Voting, Yamhill Vote by Mail, and other Total presentations are retained as source-specific overlapping methods. Their names do not prove a uniform statewide method definition.

Historic native extraction is **partial** despite complete retained ZIP bytes and complete county abstract controls. Some archive members omit relevant federal pages (Benton 2020 is state offices only); its full county-hosted 262-page original was separately recovered. Other scanned/multicolumn sources need further original-row normalization. Their unavailable cells, unresolved administrative identities and unparsed membership are not zeros. Do not infer source absence, statewide native completion or a cross-year key/geometry crosswalk from archive filenames, county totals or shared labels.

## Contract and exact arithmetic

`priority-set.json` has all 36 county parents. Canonical complete order, ordered priority keys, top15, minimum80 and remainder are **null**, because 31 current-priority-year native universes are unclosed. Every acquired verified 2024 constituent and its available source presentations are included under its parent. Every unavailable parent has an explicit case. The full historical normalized observation inventory and its unresolved groups are linked separately. All source/current/geometry/peer/coordinator approval flags remain false or pending.

`known-native-order.csv` and `known-native-ranking.json` rank the qualified 510-unit universe only. Unknown parents retain **1,115,972** presidential candidate/Misc votes in statewide arithmetic and unknown native membership; those votes are not assigned to proxy county units. Known-set 80% is not statewide 80%. Source-native IDs are versioned within county/election; a number is not a current result ID or polygon.

All orders use descending integer reported votes, then ascending full versioned key/FIPS for ties. Top15 shares are exact numerator/denominator fractions. Minimum80 is the first cumulative row satisfying `5*cumulative >= 4*denominator`; its predecessor must fail. Named-only and source-generic scopes are separate. Decimal percentages are display derivatives. The remainder always includes every ordered row outside that scenario's threshold, including explicit zeros.

## Reproduction and checks

From the repository root, run `extract_originals.py`, `extract_acquired.py`, `county_controls.py`, `participation_controls.py`, `nonadditive_presentations.py`, `native_extract.py`, `build.py`, then `report.py` using paths under `senate/2026/oregon/data/turnout/scripts/`. The original extraction uses Poppler; OCR refresh additionally uses Tesseract, PyMuPDF/Pillow and temporary restored PDFs. The retained OCR/TSV and direct visual transcriptions permit the normal offline build without rerunning OCR. `acquire.py KEY URL PARENT_KEY` is the bounded acquisition entry point; receipts contain the actual replayable URLs. Existing keys are immutable/idempotent; use a new key for a genuinely new observation.

Run `validate.py --write` to generate deterministic `validation.json`, then `seal.py` once to pin the immutable pre-peer witness and asset manifest. Run `validate.py` to check the final sealed package without modifying it. Asset-manifest self-hashing is explicitly excluded; all other owned files, including validation and witness, are inventoried. Shared originals are pinned by exact stored/raw hashes and reconstruction recipes. Validation distinguishes passing complete county controls and five native source groups from unavailable canonical priority and incomplete historical normalization. Peer agreement and coordinator acceptance have not happened.
