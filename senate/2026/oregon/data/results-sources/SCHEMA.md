# Source package schema and offline reproduction

This is bounded research, with all current/native/geographic/legal80/cadence/remainder/collector/probability approvals false or unknown. The coordinator alone accepts and publishes. External acceptance authority: `data/coordinator-source-research-acceptance.json`, path only. Its complete body was consumed in memory at launch; it is not copied, hashed, reverse-pinned or used as an optional build gate in this package.

Run from the repository root, with no cache/dependency installation:

```sh
PYTHONDONTWRITEBYTECODE=1 python -B senate/2026/oregon/data/results-sources/scripts/build.py
PYTHONDONTWRITEBYTECODE=1 python -B senate/2026/oregon/data/results-sources/scripts/check_coverage.py
PYTHONDONTWRITEBYTECODE=1 python -B senate/2026/oregon/data/results-sources/scripts/replay_inputs.py
PYTHONDONTWRITEBYTECODE=1 python -B senate/2026/oregon/data/results-sources/scripts/replay_originals.py
PYTHONDONTWRITEBYTECODE=1 python -B senate/2026/oregon/data/results-sources/scripts/audit.py
```

`build.py` without flags computes all seven derivative bodies in memory and compares their bytes, without writing. `--write` is the only derivative writer. Reproduction reads the fixed owned acquisition index, findings/report template and individual immutable catalogs. It does not read the current news manifest/helper, producer directory enumeration, optional current coordinator reviews or an unfinished peer package. No producer module is imported or executed. Poppler `pdftotext` is needed only for the independent whole-original PDF re-extraction; retained raw bodies and prior text hashes remain available without OCR reruns. Requests is needed only for acquisition, not offline validation. All scripts use Python -B; no caches/dependency directories belong here.

## Full historical inputs and resolver

`references/current-files.json.gz` contains all5,029 exact individual path/byte/SHA references from the frozen producer/source set. `whole-companions.json.gz` has1,994 full JSON/CSV/JSONL companions and their complete semantic hashes/types/lengths. `contract-pin.json.gz` pins the entire23-root contract; `contract-root-semantics.json.gz` checks each whole recursive root. `ordered-ledgers.json.gz` references all four complete ordered JSONL ledger partitions, their stored and decoded bytes/hashes and495,672 recursive container references. These catalogs preserve source-object metadata; none is a copy or receipt/hash of the external acceptance authority.

JSON is parsed whole. JSONL becomes a full ordered array of every line object, including nested raw dictionaries/controls. CSV semantics use the complete header and every full string row, retaining blanks and extra trailing fields. Semantic SHA is SHA256 of UTF-8 `json.dumps(ensure_ascii=False, sort_keys=True, separators=(',',':'), allow_nan=False)`. Traversal is preorder through every dictionary/list container, preserving insertion/array order and JSON-pointer escaping (`~0`, `~1`). Every scalar field participates in its enclosing recursive semantic hash. Nothing becomes a votes-only projection.

`historical-resolvers.json.gz` retains all5,261 complete old-path/original-size/original-SHA storage records. A record selects an exact pinned tar.gz container/member, a lossless gzip body or a direct stored body. `resolve.py PATH EXPECTED_SHA` writes the entire exact body to stdout. It uses a current file only if its frozen SHA equals EXPECTED_SHA; otherwise it searches complete immutable historical storage. It never substitutes newer bytes merely because a pathname still exists. The full replay validates every historical body independently, including superseded proofs, seals, scripts, reports and manifests. Archive and individual-reference roles remain explicit.

A `whole_ref` has `file` (full immutable path/bytes/SHA), `pointer`, `whole_object_semantic_sha256` and the literal complete-retention role. `resolve_object()` reconstructs the entire JSON/JSONL/CSV object at that position and verifies all its fields recursively. An object reference is not a new source-original body or an extraction repair.

`replay_originals.py` reads the exact pinned48-record producer receipt input, independently reconstructs all37 complete acquired metadata bodies, verifies every original entity/ordered gzip part/request body, both ZIP streams and72 member names/ordinals/CRCs/hashes, and independently re-extracts all113 original entity/text records. Large ZIPs exist only in temporary memory/storage. Whole originals remain once/byhash at individually pinned shared paths. The original inventory includes every full unrelated page in a necessary original; these were not separately researched or added to election arithmetic. Complete original retention and partial native normalization are distinct.

## Owned source captures

`requests/KEY.json` records the literal requested URL, method, parent constructor/navigation provenance, UTC retrieval, every received redirect/entity status/header/body and exact errors. Bodies use deterministic gzip (mtime0), SHA256 of stored and decoded bytes, raw/stored byte counts and ordered <=32,000,000-byte parts. Every stored file is strictly less than40,000,000 bytes. Requests exposes entities after HTTP Content-Encoding decoding; these are exact decoded entity bytes, not a claim to capture TLS packets or compressed wire framing. An empty redirect entity is preserved as zero bytes rather than omitted. DNS/TLS failures have no HTTP entity. Unusable307/no Location,401,403,404 and challenge200 bodies survive as evidence.

The acquisition code's configured GET User-Agent is retained in the script. Routine GET captures did not separately serialize requests' implicit default outgoing headers/effective percent-encoded wire URL; those fields are **unretained request-metadata qualifications**, not reconstructed observations. Literal URL/method and all received entity headers/bytes are retained. The SOAP and CSV POSTs additionally retain exact submitted encoded bodies and configured request headers. No claim of complete wire-level request headers is made. A preliminary sandbox probe before durable acquisition failed DNS with no HTTP entity; the durable same-route failure is retained separately. No partial HTTP response is labeled complete after a transport exception.

`structures/KEY.json.gz` is whole-source inspection: HTML token stream with original line/column, literal attributes/hrefs, comments, scripts, forms/options/hidden fields, entity references and all text; complete resolved link list; complete PDF `pdftotext -layout` output/page separators and `pdfinfo`; or whole JSON/CSV/text. Charset selection uses declared markup charset when present; raw bytes always remain authoritative. HTML-parser text is a locator derivative, not exact rendered copy. Script/config text remains complete. PDF raster-only cells stay unknown unless explicit visual readings exist. A no-browser static inspection is not claimed to be a successful browser session.

`acquisition-index.json` freezes every exact request/structure pin. Acquisition plans retain actual navigation/constructor arguments and rejected URLs. `acquire.py` is immutable-key/idempotent and stops excluded auth/social/admin redirects; `directory_post.py` performs only the observed anonymous read-only SOAP request; `staging_export_post.py` performs only the observed public CSV postback and labels it staging negative. No live polling collector or probability implementation exists. Do not replay the acquisition scripts as part of offline rebuild. Browser/account/login operations, challenge bypass and outreach were not used.

Explicit `observations_unit_key` bindings locate full normalized objects and every raw observation, including full CSV dictionaries, candidate labels/choice IDs, native IDs, raw positions, nonvote controls, method and administrative counters. ## Seal, proof and membership

`fixtures.json` records in-memory corruption/scope tests against the actual coverage/resolver/packaging checks. Shared files are never mutated. `history/` preserves bounded decisions and unretained-attempt qualifications. `validation.json` is deterministic pre-seal proof metadata. `finalseal.json` pins validation and fixed key inputs; it has **no current-manifest hash**. `asset-manifest.json` is written last and enumerates every owned report, CSV, source, script, proof, history, validation and final-seal body, excluding **only itself**. Its entries are Oregon-relative paths and SHA256/byte counts. All three ownership scopes are audited; no producer/shared path is written.

After sealing, `audit.py` performs a read-only full membership/hash/size/link/coverage/source replay, deterministic derivative comparison and whole historical/original reconstruction. No owned write follows this audit. Final manifest's SHA is an external handoff pin, never a reverse pin in validation/finalseal. Coordinator acceptance is deliberately false and no self-acceptance is implied by a passing worker audit.
