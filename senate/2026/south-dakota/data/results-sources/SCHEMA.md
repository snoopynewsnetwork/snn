# South Dakota official-source evidence schema

All paths in manifests, the complete contract, and the authority CSV are relative to `senate/2026/south-dakota`. Paths within this directory's receipt/inspection files are relative to `data/results-sources`. External acceptance is resolved **only by** `data/coordinator-priority-acceptance.json`. No acceptance hash is written back, no worker acceptance flag changed, and this package does not approve itself.

Huge originals are not copied.

Each reference resolves a **complete** original unit by JSON pointer and semantic digest. `finer_historical_locator` preserves each original constituent object verbatim. The latter has39 records, exact ordered priority and all native child keys, exact requests/controls, local statuses and discovered links, and finer/current gaps. ## Acquisition and original bytes

`jobs-*.json`: explicit finite requests, each with exact observed parent/anchor or a literal client constructor explanation. No guessed contest IDs, APIs, or autonomous collector. POSTs are read-only ASP.NET export controls: the full hidden form values and `__EVENTTARGET` are recorded. Parent IDs refer to immutable receipt IDs; discovery roots identify their primary source.

`raw/<id>.receipt.json`: method, requested `url`, `final_url`, ordered redirects (URL/status/full headers), status or null on local transport failure, UTC start/completion, complete response headers, error or null, raw entity byte length/SHA256 and ordered stored-part pins. Bodies are complete HTTP response **entity** bytes after requests' HTTP content decoding, not compressed wire framing. `body_kind=complete_local_exception` marks a saved complete exception string when no HTTP response existed. HTTP errors retain complete response bodies. Empty/unavailable is never repaired into data.

Every body is losslessly gzip-compressed with deterministic mtime0 and split into32,000,000-byte parts. Concatenate in order then decompress; `reconstruct.py` verifies each part, full stream and original. Every stored artifact is strictly below40,000,000 bytes. The frozen2020 county original uses its existing four gzip parts32M/32M/32M/6,882,528, not a nonexistent standalone `asset`; its full149,141,181 raw bytes and original SHA256 are streamed and verified.

`source_clock` and `source_timezone` start null in acquisition receipts because fetching does not interpret publisher time. Parsed observations below preserve clock literals and scope. HTTP Date, ETag and Last-Modified describe transport/publication objects; they are not automatically vote-update clocks or correction/version sequences. Dynamic export download clocks remain separate.
