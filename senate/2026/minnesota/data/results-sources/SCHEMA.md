# Minnesota official-source evidence schema

All data are research observations. `general201-setup-inspection.json` has `admitted_to_current_counts:false`; no collector or production feed is configured.

`raw/<id>.body.gz` decompresses to the complete requests-decoded HTTP entity, including failures and challenge bodies. Wire transfer compression/chunk framing is not retained. `<id>.meta.json` records requested/final URLs, every requests redirect response with headers, request-start UTC, status, response headers, raw/stored lengths and SHA256, parent and observed-link locator. A successful HTTP response is not a successful results parse. Shared originals have their original capture limits explicitly recorded; missing historical redirect traces are not invented. Requests are one public GET per task,35-second timeout, no auth, no retries, max4 concurrent fetches. Tasks are bounded explicit lists; no recursive crawler or private API guessing. New observations use new IDs.

`raw/*.links.json` contains HTMLParser tag/attribute values, exact decoded-HTML character offset, line, column and link index, and resolved URL. These are character positions in the requests-selected decoding, not asserted original byte offsets. Original bytes remain authoritative. `*.text.txt` is a derived HTML text stream, may include script text, and is not an election-data format. `web-*.json` retains exact tool-returned provider text with source chains and rendered line positions. It is not original HTML or an HTTP-header record. `web-observation-ledger.json` explicitly distinguishes capture-completion UTC from unavailable provider retrieval UTC.

`native-2024/2022/2020.jsonl.gz` preserves every original precinct row and every cell in order, including address, attributes/type/style, raw OOXML value, resolved string and complete cell XML. `headers_by_column` prevents overwriting duplicate2020TABMODEL G/R. Blank/absent cells and source zeroes differ. `workbook-context-*.json` preserves all non-precinct sheets, including Notes, Fields, Counties with actualCountyFIPS, Districts and voting equipment. SourceCounties lookup supplies FIPS; it is never computed from internalCountyCode. These retained XML/JSON extracts are derived from the complete primary XLSX originals referenced by hash, not claimed standalone published XML/JSON result endpoints.

`county-native-contexts.jsonl.gz` contains each complete frozen `county_order` object in exact rank order, including all12,316 original constituent objects and unavailable/administrative contexts. Nothing is generalized. `/county_order/<rank-1>` in the frozen contract is the exact input locator. Source municipality/ward/PCTCODE/VTDID are context within the disjoint county accounting aggregate. No cross-year or current geometry/reporting-unit join is approved.

`export-*.rows.jsonl.gz` records every line in original order,1-based line and exact byte start/end in the raw entity, plus every semicolon field including empty strings. Text is decoded cp1252 without altering original bytes. Result files have16 fields (zero-based):0State,1CountyID,2precinct slot,3OfficeID,4OfficeName,5District,6CandidateOrderCode,7CandidateName,8Suffix,9IncumbentCode,10PartyAbbreviation,11PrecinctsReporting,12TotalPrecincts,13CandidateVotes,14CandidatePercent,15OfficeVotesInArea. The layout calls field2 precinct name, while actual inspected precinct files contain precinct codes such as0005: preserve this schema/documentation mismatch. CandidateOrderCode is not automatically the8-character candidateID. `cand.txt` supplies the latter separately. No method dimension exists in these candidate rows.

`pctstats.txt`:0State,1CountyID,2PrecinctID,3PrecinctName,4HasReportedStatistics,5REG7AM,6EDR,7SIGNATURES,8regular/military/overseas absentee/mail,9federal-only absentee,10president-only absentee,11TotalVoted. The2022 workbook has no PRESONLYAB column; the export's field10 is retained and not invented into that workbook. Administrative statistics are not Senate candidate votes or outstanding Senate votes. `PrctTbl.txt` and municipality tables preserve source district/MCD fields; unorganized-territory MCD FIPS may differ from Census per official layout.

`historical-controls.json`, `export-reconciliation.json`, `additional-historical-reconciliation.json` independently reconcile originals to fetched text, with differences retained field by field.2022county totals are independently aggregated from actual governor precinct exports; no direct county export is claimed.2020and2024 have direct county Senate exports. `canvass-2020-positions.json` has435 main-report candidate/county positions and522 separately named write-in appendix positions, with PDF page, page-text line, exact global character spans and untouched text line. Named32 overlaps generic2261; no addition or residual allocation.

`hours-exceptions.json` preserves286 current SOS workbook entries, including18 primary-only rows excluded from November's268 exceptions. Original Excel fractional times and strings remain. Source says July28,2026 update and covers both elections unless noted, excluding mail precincts. Current county/code/name context is not joined to historical VTDIDs. Local times are America/Chicago; statutory in-line/relocation exceptions remain possible. `authority-inventory.json` contains all87 authorities and depth/access evidence. `priority-investigations.json` contains exactly24 individually researched records; blocked channels and unresolved feeds remain explicit.

`input-pins.json` pins coherent read-only inputs, including acceptance by PATH; no reverse hash in the frozen contract. `shared-source-provenance.json` copies complete individual immutable capture records, not a mutable peer aggregate dependency. `asset-manifest.json` covers every owned file, including report/CSV/scripts/validation, excluding only itself. No recursive hash cycle. Run `validate.py` without flags to validate without changing any file. Use `--record` only before regenerating the manifest.
