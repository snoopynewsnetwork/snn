                Understanding Election Results

                    
                        Election officials compile results by:

Using a ballot tabulator to add vote totals
Accepting absentee ballots
Reviewing and proofing unofficial results

Election officials certify results by:

Auditing and proofing results
Certifying local results through the County Canvassing Board
Sending results to the Office of the Minnesota Secretary of State
Certifying state and federal results through the State Canvassing Board

    $(document).ready(function(){
        let lastCtrlTime = 0;
        // milli seconds
        const doublePressWindow = 500;
        document.addEventListener('keyup', function (event){
            if(event.key === "Control"){
                const now = Date.now();
                if(now - lastCtrlTime <= doublePressWindow){
                    let metaPageId = document.querySelector("meta[name='pageID']")
                        .getAttribute("content");
                    // reset time
                    lastCtrlTime = 0;
                    var backofficeEditUrl = window.location.protocol + '//' + window.location.hostname + '/umbraco/#/content/content/edit/' + metaPageId;
                    window.location.href = backofficeEditUrl;
                }
                else{
                    lastCtrlTime = now;
                }
            }
        });
    });
