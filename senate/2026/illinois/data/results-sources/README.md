# Illinois official-results evidence package

Owned scope is `../../official-results.md`, `../official-results-sources.csv`, and this entire directory. Relative evidence paths inside JSON resolve from `senate/2026/illinois`. Only `asset-manifest.json` is excluded from its own exact membership list. No cache/dependency directory is permitted.

External authority is path only: `../coordinator-priority-acceptance.json` from this directory's parent data directory (state-relative `data/coordinator-priority-acceptance.json`). Do not pin/copy its digest/body, alter producer flags, execute producer writers or replace immutable originals with an appendable acquisition ledger. `original-asset-references.json` pins the individual immutable inputs/originals actually reused. Optional unfinished peer/coordinator artifacts are not dependencies.

## Offline reconstruction and QA

Run from the repository root, with Python 3 and the already installed requests package. No package installation is needed. All these commands are offline:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B senate/2026/illinois/data/results-sources/replay_frozen.py
PYTHONDONTWRITEBYTECODE=1 python3 -B senate/2026/illinois/data/results-sources/schema_samples.py
PYTHONDONTWRITEBYTECODE=1 python3 -B senate/2026/illinois/data/results-sources/build.py
PYTHONDONTWRITEBYTECODE=1 python3 -B senate/2026/illinois/data/results-sources/describe_sources.py
PYTHONDONTWRITEBYTECODE=1 python3 -B senate/2026/illinois/data/results-sources/offline_replay.py
PYTHONDONTWRITEBYTECODE=1 python3 -B senate/2026/illinois/data/results-sources/validate.py --write
PYTHONDONTWRITEBYTECODE=1 python3 -B senate/2026/illinois/data/results-sources/seal.py
PYTHONDONTWRITEBYTECODE=1 python3 -B senate/2026/illinois/data/results-sources/validate.py --manifest
```

The final `validate.py --manifest` is read-only, including its full 554,096-object replay. `--write` deliberately writes owned `validation.json`. `offline_replay.py` reexecutes only named owned reconstruction scripts, checks exact generated byte stability, then writes its owned replay result. Do not rerun acquisition after sealing. Rebuilding changes no external producer files. `seal.py` must follow any intentional owned edit; it covers QA scripts/results, report, CSV, receipts, full bodies, samples, rendered pages and all other owned files.

`schema_samples.py` preserves all rows and structural objects, source header/order/null/party/status differences, every worksheet cell and the full original ZIP reference. Recursive schema order comes from the source parsing before sorted serialization. Full raw source bytes remain authoritative for every HTML/ZIP field not modeled by the parser.

## Bounded acquisition scripts

Acquisition is a reproducible one-pass public research workflow, **not a collector**. Scripts retain existing immutable receipt IDs rather than refresh them. They require public networking and should be reviewed with their exact stored plans before any new run; optional network availability is not an offline build dependency.

| Stage | Owned implementation |
|---|---|
| State directory/navigation | `acquire_state.py`, `follow_state.py`, `directory_details.py` |
| Official county/city landing attempts and bounded literal links | `acquire_authorities.py`, `follow_authorities.py`, `discover_vendors.py`, `deep_public.py`, `gap_sources.py` and complete `*-plan*.json` inputs |
| Actual candidate print/download controls | `candidate_request.py`, `candidate_downloads.py`, `current_scope_follow.py` |
| Observed vendor constructors/full files | `follow_data.py`, `clarity_samples.py`, complete public scripts/config receipts |
| Legal search/primary acts/orders | `acquire_legal.py`, `legal_follow.py`, `acts_ftp_follow.py`, `final_legal_sources.py`, `timezone_sources.py` |
| Actual public FTP directory chains and selected sections | `ftp_status_chain.py`, `ftp_code_chain.py`, `ftp_code_follow.py`, `ftp_code_election.py`, `ftp_complete_code.py`, `statutory_sections.py`, `revisory_status.py` |
| Verified TLS transport/receipt helper | `common.py`, `curl_evidence.py`; no certificate bypass or challenge workaround |
| Lossless owned storage normalization | `compact_evidence.py`; preserves complete stored bytes and old-name mapping |
| Text/marked law and selected-page rendering | `pdf_extract.py`, `legal_extract.py`, `statutory_review.py`, `visual_previews.py`; external installed Poppler tools used for PDFs |

`common.fetch` keeps complete decoded response bodies below its explicit 15 MB bounded response limit; exceeded/failed bodies are not admitted as complete. All actual stored objects remain strictly below 40 MB. `fetch_curl` uses system certificate verification after the requests backend's certificate failures, preserving its exact command, full header blocks and curl result metadata. In the actual curl observations there were no redirects; requests observations preserve each redirect status/headers/body. Error pages are complete bodies when available. No November IDs are constructed by analogy to a historical/primary product.

Read `discovery-scope-findings.json` for the early irrelevant GETs and diagnostic metadata limitations. The corrected boundary guard applies to public-link navigation. No current feed or joined geography is approved; every parent/current leaf admission remains false/null. This package cannot be used as a live collector configuration.
