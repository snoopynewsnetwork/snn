# NJ map package schema and reconstruction

All paths below are relative to `maps/` unless explicitly state-relative. Owned paths are only `../precinct-maps.md` and this tree. Every file must be strictly below 40,000,000 bytes. SHA-256 covers exact bytes. JSON serialization retains nulls and native integer/float values; original response bytes remain authoritative for number lexemes, attributes, coordinates, curves and invalid cases.

`historical-contract.json.gz` reconstructs the complete frozen primary JSON, all 24 root fields and all 575 full objects; no producer flags are changed. Ranking is descending numeric six-published-candidate volume and exact source-position key lexically. These are publication observations: 564 municipal labels and 11 administrative rows (10 federal/overseas variants and Atlantic HandCounts), not a current finest precinct universe. `original-dependencies.json.gz` retains the complete 417-entry original reference list with complete embedded receipts/failures. `individual-source-pins.json` pins individual immutable external bodies. The external acceptance is used only at its path; no acceptance body/hash is owned or reverse pinned.

`scripts/reconstruct.py` independently re-executes complete original reads and recursive comparison over every required object. Its implementation is transparently adapted from the completed official worker's read-only algorithm; that worker's output review is not an input. The script verifies all 24 roots, 504 complete companions, five complete ordered JSONL-gzip partitions / 724,943 complete recursive objects, both producer manifests and all 2,654 listed bodies, and all 417 original dependencies including 155 no-body failures. CSV headers/rows, candidates/party/position, raw lines/nulls, ballots/registration/methods, controls, parents, finer constituents, scenarios and original receipts are included; no selected-only/vote-only projection replaces them. Producer writers never execute.

`inventory.json` has exactly 575 records. Each retains the unchanged complete `source` object, complete original-derived candidate row and definitions, source-publication reference, parent FIPS, priority membership, qualified shared-resource references and specific vintage/access/finer/physical/current gaps keyed to that source position. Physical/current matches are null, not invented zeros or name joins. `manifest.csv` is an operator index, not the full-object preservation layer.

`parents.json` has exactly 21 records. Each includes the complete historical county object, all three distinct official authority-role fields and links, all canonical rank/source/priority/remainder children, actual shared acquired state/Census resources, county feature references, bounded map/companion catalog, relevant full receipts and county-specific findings. County membership links parent resources; it does not equate a municipal/admin label, ward, poll site, VTD GEOID, state `ELECD_KEY`, vendor `PrecinctID`, ballot style or reporting unit.

`authority-directory.json` preserves full text of all three published roles in all 21 directory sections, including names, addresses, hours, phones and actual links. The entire original HTML is retained. Roles are not merged when links coincide. Every new request has its own `receipts/<ID>.json`, with all complete hops, request method/URL/headers/query/body, actual requested/final URL, parent/literal href, retrieval/finish UTC, response status/reason/full header list, full body hash/length/ordered stored-part hashes, or exact network error. Client failures are not HTTP statuses. HTTP200 shell, HTTP202 empty body, metadata-error JSON, primary/old/future data are not current returns or usable boundary geometry.

`originals/<rawSHA>.gz` losslessly wraps a complete received body. Reconstruct by concatenating `stored_parts` in receipt order and gzip-decompressing once. Further HTTP content decoding uses the retained Content-Encoding only for interpretation. Shared original bodies are deduplicated by hash; separate observations/redirect receipts remain separate. There is no huge original cache or dependency tree.

`qa/*-native-contract.json` records complete pre/post metadata equality, counts and ID sets; all original advertised ID orders; all exact requested and returned batch ID arrays; differences and raw hashes. Each native batch requests all attributes and geometry plus Z/M/true curves, with no output CRS, precision, rounding, quantization, simplification, offset or repair parameter. Complete original service/layer metadata and full batch SR objects are retained. Burlington extent SR additionally has tolerance/origin/unit fields; the returned SR is a smaller matching form. All returned SR fields, including wkid/latestWkid, must agree with metadata; the extra extent fields are not silently injected into a batch.

`native-feature-index.json` contains all 6,348 statewide and 401 Burlington feature attribute objects, source receipt/feature index, and diagnostics. Original full geometries are recovered by `scripts/inspect_original.py native RECEIPT FEATURE_INDEX` or the atlas local gzip picker, without projection or repair. State fields include literal `ELECD_KEY`, county/municipality codes, ward/election district labels and area/length. Burlington retains every fully qualified joined field, native precinct/polling IDs, nulls, timestamps and internal user strings. None becomes an approved current result key. State item metadata says mature support, no longer updated, historical reference only; item-modified and last-edit clocks differ.

`derived/census-vtd-native.jsonl.gz` has all 6,361 original DBF records, deletion flags, complete attributes, original field-cell hex and native shape type/bbox/part indexes/points. No ring is reordered, closed, nested into holes, repaired or projected. Original ZIP includes all seven members. `qa/census-vtd-audit.json` includes member sizes/hashes/CRC, complete DBF header/descriptors/trailing bytes, SHP/SHX headers, PRJ/CPG, inspected reader version/module hash and all-coordinate bitwise hashes. `qa/census-vtd-every-record.json.gz` retains every record number/offset/length/DBF deletion flag/body hashes/bbox and part diagnostic. The actual polygon reader supplies explicit points+parts; its optional `lines=` auto-close branch is not used. Empty/orphan shapes bypass that constructor and remain original. Native geographic degrees are not feet or geodesic legal areas.

`qa/native-diagnostics.json` retains each original feature's null/empty/curve/linear classification and linear closure/part/vertex/bbox/adjacent-duplicate checks. Native curve objects are preserved without linearization; previewing would skip curve parts rather than chord them. This snapshot has 6,749 linear-ring feature objects, but fixtures preserve other cases. Without an operative outline and legal crosswalk, these checks do not certify gaps, overlaps or slivers.

`preview-index.json` describes each of 21 county previews: exact original-native extent and affine pixel transform. PNG linework uses every original linear vertex, without reprojection or vote shading. Previews are separate artifacts, never substituted for geometry. `pdf-inventory.json` retains original hash, PDF metadata and every physical page, page dimensions/rotation, full extracted text and preview hash. Rendering preserves source page orientation; preview scaling is documented. `derived/pdf/<hash>/` contains all pages and `all-pages-text.json.gz`. A source PDF can be physically one page while printing Page2of2; the Gloucester Mantua roster is explicitly such a partial source document, not a full county roster. Empty text from a scan remains empty, not zero. Actual viewing is limited to `qa/visual-review.json`.

`atlas-data.js` is a safely escaped derivative containing the complete contract, 575 full inventory objects, 21 full parents, all 84 historical county-publication objects across four candidate scopes, full map/PDF catalogs, complete receipts and all native attributes. Its original-derived candidate scopes retain 2020 Booker–Mehta ClassII (571 rows/4,440,540), 2024 Kim–Bashaw ClassI (575/4,031,795), 2018 Menendez–Hugin midterm ClassI (575/3,169,310), and separate 2024 president (575/4,272,725). No2022Senate/governor is invented. Full historical receipt/body controls remain external individually pinned inputs. Exact Neptune labels/vectors, Somerset2022+420, SOS2020versusHouseClerk+61/+39, literal Somerset presidential Kenndy caption, protected/suppressed/null fields and overlapping methods remain unallocated.

The atlas uses textContent, never source-supplied HTML. Filters cover all/priority/remainder, all21counties, whole source objects, rank/source order and all native attribute records. Full source, county/hierarchy/four-contest objects, map pages and original JSON remain displayable without truncation. Original-file decompression is local. Node tests exercise actual JavaScript and gzip handler, not a browser rendering engine; no browser layout/Chrome approval claim is made.

`qa/reproduction.json` pins before/after deterministic products from offline original-only reconstruction, full native audit, previews/full PDF text, inventory and actual JS/negative tests. `qa/validation.json` records complete source/dependency/coverage/native/size/link checks. `final-seal.json` references those validation products without a reverse manifest hash. `asset-manifest.json` includes every owned file except only itself; `scripts/verify_seal.py` verifies the exact set and bytes read-only. External source/current/legal exhaustion is a qualification, not an unfinished owned gate. All current-geography, choice/reporting-ID, genuineNovember-return, cadence/remainder, collector, forecast and probability approvals remain false.
