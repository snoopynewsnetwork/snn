# New Jersey partisanship source, geography and arithmetic schema

Owned state-relative paths are `county-partisanship.md`, `data/county-baselines.csv` and `data/baselines/**` only. Scripts use their own directory to resolve outputs. No Git, shared, peer or other-state writers are invoked. Standard Python, Poppler `pdftotext`, PyMuPDF and requests suffice; no retained dependency/cache directory is needed. Source-critical prose and CSVs are generated from independent original extracts, without a peer vote/rank or mutable news-manifest build dependency.

## Original evidence and clocks

`original-references.json` freezes416 inherited receipt objects plus a separate House Clerk original reference (417 entries). Each inherited receipt's exact metadata/bytes are pinned, including failed attempts. Successful originals use `body_reference`, relative to this source directory, to existing read-only `data/turnout/source` or `data/news` bodies. Receipt paths/hashes are evidence references, not authority to refetch or mutate. For each body: original decoded HTTP entity bytes, raw SHA256/bytes, deterministic stored gzip SHA256/bytes, exact requested/final URL, source-parent discovery, UTC retrieval, response headers, redirects and HTTP status survive. `.content` decoded entity bytes are the reconstruction contract; PDF/OOXML bytes remain unchanged. The same original can have multiple receipt observations; those records are not deduplicated or candidate keys normalized.

The frozen source-reference index, rather than an appendable newsroom manifest, determines original inputs. `extract_originals.py` reads that index once it exists and verifies bodies by exact hash. No peer derivative is read by acquisition/extraction/build/report scripts. Source receipts can carry `url` or `requested_url`; missing response metadata remains missing, never invented. Client DNS/MissingSchema errors are not HTTP statuses. HTTP200 does not establish election identity, current counts or source completeness.

`public-network-*.receipt.json` and matching `.body.gz` are new bounded public official acquisitions. Initial sandbox DNS failures remain in separate `current-*.receipt.json` records. Acquisition follows only the actual current official general roster/certification/calendar links and explicit results/statute/Senate-class pages. It excludes login/reset/account/security/mail/social/administrative endpoints. It never overwrites a receipt. A new observation needs a separately named receipt; this package is a snapshot, not a periodic collector.

Current new retrievals occurred 2026-10-20 UTC (October19 Central). Inherited acquisition UTC is retained literally (October18/20); printed source dates and HTTP Last-Modified are independent clocks, not silently merged. The current general official list and certification attachment are printed07/27/2026, calendar updatedJanuary9. Senate county PDFs are2024December5,2020October14,2021,2018December3. Native PDF printing clocks can differ and remain in complete layout text. Neither date differences nor source headers alone prove a correction cause.

All originals reconstruct losslessly by gzip decompression, or direct bytes for the shared House Clerk PDF. Every stored artifact is strictly less than40,000,000bytes; no truncation, simplification, source allocation or huge duplicate original is used. Original references are externally pinned dependencies within the shared repo; owned derivative/frozen-review bodies have their own manifest membership.

## Live JSON contract and strict errors

Top-level:nonempty `units`, finite numeric `target_margin`[-1,1], `denominator`=`pair` or `all`, optional exact `expected_keys`, optional existing `selected_key`. Every unit has unique nonempty string `key`; counted object has nonnegative integer `A`,`B`,and distinct named `others` map; remaining explicitly has nonnegative finite `contest_votes` or null, `pair_fraction`[0,1]or null, `a_pair_share`[0,1]or null, finite optional `share_shift`, and `other_mix`map. A positive remaining other pool requires a mix summing to1. Unknown remains unknown. Zero-pair pools can leave irrelevant preference null. No missing field becomes zero. Null/bool/text/NaN/Infinity/out-of-range targets and duplicate/missing/invalid keys are rejected even without a selected key. Arithmetic outputs must be finite; safe errors are JSON with exit2 and no traceback. Valid unknowns use null instead of Infinity/NaN.

Final pair denominator=countedA+countedB+ΣUp; final all-candidate denominator=all counted candidates+ΣU. Required common remaining share=(mF−countedLead+ΣUp)/(2ΣUp). Selected-only holds all counted and all other remaining q fixed. Other candidates remain separate. `synthetic/*` and `calculator-tests.json` contain meaningful feasible, denominator, unknown, no-pool, negative, impossible, secured, clipping, third-candidate and corruption cases; probabilities remain null.
