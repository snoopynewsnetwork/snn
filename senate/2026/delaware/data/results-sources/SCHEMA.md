# Delaware official-source package schema

This package owns only `official-results.md`, `data/official-results-sources.csv`, and this directory. All paths in full-body references are relative to `senate/2026/delaware`. External acceptance is a path-only authority; it is read/verified at launch in memory, never copied/reverse-pinned. Every other immutable source reference carries exact complete file bytes/SHA256. A reference plus JSON pointer or one-based `JSONL_record` identifies the full recursive value, never a vote projection. Empty pointer means the entire parsed object. Semantic SHA256 uses UTF8 JSON with sorted keys, no ASCII escape, compact separators, no NaN. Original byte hashes remain separate.

`frozen-references.json.gz` contains the full contract pin, 42 root-field semantic references, 42 complete companion file pins/schemas, all16,388 full-object semantic references and353 unique producer-sealed asset pins. Companion reconstruction is exact gzip decompression where applicable, JSON/JSONL parse or CSV reader preserving every header/cell/row/order. No projected replacement is valid. Existing producer manifests and false flags are read-only. `freeze.py` validates the entire external acceptance and independently reconstructs full pinned constituent bodies. `reconstruction-override.json` documents replacing legacy mutable newsroom-manifest discovery with exact frozen individual source receipts. Producers are not executed and optional coordinator/news/maps reviews are not imported.

`raw/ID.receipt.json` records a single immutable explicit bounded public request: requested/final URLs, parent ID/literal href or observed constructor, GET method, literal query, null body, request headers, retrieval UTC, status or exception, ordered full response-header pairs, all redirect records and their complete body assets, original/stored byte counts and SHA256, entity scope, and false November admission. Raw `.body.gz` files are lossless deterministic gzip of complete HTTP entities. HTTP errors/empty bodies remain, with explicit status/exception. `Accept-Encoding: identity` distinguishes transfer-decoded entity bytes from wire packets. A transport/probe limit never permits truncation: oversized responses fail, not admit partial data. Plans specify literal discovered requests; they are acquisition replay inputs, not endpoint generators. A fresh observation requires a new ID. `source-index.json` pins the exact owned receipts/bodies; it is not an external mutable newsroom aggregate.

`historical-source-receipts.json` freezes full individual producer receipts for selected HTML/CSV originals. `historical-auxiliary-receipts.json` includes12 complete shared official originals/receipts including write-in PDFs/calendar. Exact original compressed files are reused read-only without huge duplication. Historical receipts did not retain intermediate redirects; that limitation remains. Filename suffix `.html.gz` does not determine actual content type. `extracts/historical-all-fields.json.gz` independently extracts complete HTML tables/links/scripts/forms or complete CSV rows, and references the entire original PDFs, whose full text is also retained. Selected raw source object bodies and every complementary field remain available through immutable references even if a derived extract omits a presentation property.

`extract.py` uses Python's standard-library HTMLParser/regex with explicit UTF8 decoding. The code site's meta tag falsely says UTF16; byte-aware guessing is not used. Each table preserves all attributes, caption raw HTML/text/positions when present, all rows/cells, ordered raw attributes, exact decoded cell text, normalized display text, original start/end character offsets. Full original source slices reconstruct every tag/entity/whitespace. Table/cell offsets refer to the decoded original entity; directory section nested table offsets are relative to that section, with its absolute `source_start` supplied. Raw text and normalized text are distinct. All links retain raw attributes/href/text and resolved URL. Scripts retain full inline bodies/attributes/source positions, forms/selects full raw HTML. Search selectors and DOM/ballot order are not native IDs.

CSV extracts retain the complete literal header, every row/cell as strings and original ordering, without automatic number/date/null coercion. Actual current PR2026.csv has829 rows/11columns/12 electiondate values, so a row must pass electionname/date/office/party/candidate/clock scope before any comparison. No whole-file count admission by HTTP200/filename is supported. XLSX evidence retains the complete ZIP original plus all member names/sizes/hashes and all XML/rels strings; no worksheet/cache/body is projected away. PDF text is a Poppler derivative; original bytes remain authoritative, and automated extraction is not visual inspection.

`directory-full-fields.json` preserves all five literal office/warehouse sections, source spans, raw HTML/text, all raw table fields, original email obfuscation tokens and derived display decoding. Separate unprinted office website/results fields are null. The nine-row source CSV includes these five entries, three Superior Court county authorities and State Board. Empty CSV cells encode unavailable/not separately printed values, never zero or a fabricated link. `False` approval is explicit.

`parent-investigations.json` has exactly three county parents in frozen hierarchy order. Each documents actual shared public source/config/download/sample requests, full county Senate table pointers and the county column, directory/legal authority, clocks, and individual access/legal/candidate/statistic/native compatibility gaps. Shared payload evidence is explicitly shared; no per-leaf request is implied. No independent county website, results vendor, guaranteed interval or changing measured cadence is inferred.

`priority-entry-investigations.json.gz` contains exactly311 entries in accepted ordered priority key order. `remainder-entry-investigations.json.gz` has exactly219 entries in accepted remainder order. Each entry is election+contest+literal native key, historical source parent, complete historical observation and three full candidate-record references, actual shared-parent investigation, and explicit per-entry gaps. Current election leaf/geography/method/candidate/contest/reporting IDs are JSON null; approval false. These are source-only investigations, not a current native dispatch. `full-hierarchy.json` retains all530/full county child arrays, priority/remainder arrays and complete1495year/native union reference. `source-only-unavailable-cases.json` preserves complete six administrative and ten unavailable objects plus whole statistic/companion references, not candidate zero imputations.

`audit_originals.py` independently checks all2674 selected table headers/positions and10699 original candidate cells/labels/parties/methods/nulls against full source slices. Unlabelled historical county cells are aligned to the actual table headers; 2022 Candidate Name/Party Name labels remain distinct from other years. It independently verifies native scopes530/533/436/439/516 and controls. No producer parser/solver is imported. `original-field-audit.json` contains full ordered native scope results, not current geography approval.

`research-errors.json` records actual negative requests and researcher errors. `negative-fixtures.json` labels synthetic fixtures separately from actual responses. `validate.py` tests full raw/stored hashes, JSON field positions and recursive semantic references, original rawfields, order/coverage, CSV election scope, candidate status/identity gaps, native nulls, missing/zero/setup/primary rejection, no exact remaining pool and allfalse approvals. It does not contact the network. `manifest.json` includes every owned file except itself, plus the owned report/CSV. No cache/dependency directories are permitted. `seal.py --check` rejects additions, removals, hash/size drift or any object >=40,000,000 bytes. `reconstruct.py` emits an exact complete referenced file (optionally decompressed), with hashes checked before output; JSON pointer mode emits a full recursive semantic body. It cannot emit external acceptance.

Reproduce offline with Python3 and Poppler (`pdftotext`, `pdftoppm`):

```sh
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/delaware/data/results-sources/reproduce.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/delaware/data/results-sources/reproduce.py --check
```

Existing pinned originals/companions must be present at their exact paths. No live collector or outreach is part of reproduction. `visual-review.json` lists only images actually seen; no unseen browser/PDF scope is claimed.
