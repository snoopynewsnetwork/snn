## Acquisition entities

Each `source/*.receipt.json` stores requested/final URL, literal parent/href or observed public constructor, method, all query pairs, request body (null for GET), UTC start/end, HTTP status, full response headers, every redirect with headers/body/base64/hash, exceptions, raw content-decoded entity size/SHA and stored gzip size/SHA/path. HTTP content encoding is decoded by Requests, then the complete entity is losslessly gzipped with `mtime=0`. Thus the hash describes the decoded HTTP entity, not compressed wire traffic; headers retain transport information. Local empty DNS attempts have null HTTP status and are not source data. Requests HTTP200 alone does not establish election data or geography.

`source/reused-original-receipts.json` freezes 30 **individual complete receipts** from the immutable launch inventory. Every raw and stored body was independently checked. Exact repeated response bodies are stored once by hash and referenced read-only, including five original maps and eleven native pages. The optional source inventory/reviews are not build dependencies. The three public JavaScript originals retain the literal dataset constructor, and the Hub original retains the actual dataset ID. Fresh requests follow that observed constructor and returned service URL. No endpoint guessing, ID enumeration, authentication/admin calls or challenge bypass occurred.

`source-inventory.json` records every actual worker request, including negative attempts. `manifest.csv` gives source URL/time/format/CRS/native count/raw and stored hashes. `parent-inventory.json` retains each complete contract county hierarchy and actual county-anchor/overview/state/Census chain. Its directory link counts are source-link inventories, not physical precinct counts. `source/official-map-link-inventory.json` preserves complete literal link arrays/positions; unacquired individual ED PDFs are links only, explicitly separate from acquired full GIS and shared PDF examples.

All stored files are strictly below40,000,000 bytes. Gzip suffices for these originals; none required splitting. Reconstruction is exact whole-body decompression, never truncation or geographic generalization. The manifest covers the owned report and every owned file except only the manifest itself; external references are pinned separately, avoiding source duplication. Temporary uncompressed PDFs are removed after rendering.

## Native FirstMap geometry

`native-features.json.gz` is **native Esri JSON**, not GeoJSON: complete `attributes` plus native `geometry`, with the response spatial reference retained. Six fields: `OBJECTID` (retrieval ID), `DISTRICT`, `POPULATION`, `RDED`, `Shape__Area`, `Shape__Length`. None is a current Senate vendor/result join. `POPULATION` is a source attribute, not votes or an approved weight. Do not infer county membership: the native schema contains no county field. Source attributes are not recalculated.

Native CRS: ArcGIS102100/latest3857 (projected metres). Metadata reports XY units10,000 per coordinate unit and XY tolerance0.001; these are source precision metadata, not chosen output rounding. The layer says hasZ=false/hasM=false. Every query nevertheless requests returnZ/M/truecurves=true, returnGeometry=true and outFields=*. **No** outSR, geometryPrecision, quantizationParameters, maxAllowableOffset, generalization or transfer-offset request is used. Eleven pages contain at most50 observed all-ID values. Requested and returned ID sets and cardinalities match exactly; duplicates/missing IDs and exceededTransferLimit are rejected. Metadata/count/allIDs are captured before and after the complete pages, with exact body and semantic equality. Complete original responses retain all envelope keys and any source geometry forms.

Observed snapshot:531 features /533 rings /169,245 positions, no null/empty/truecurve geometries or null attributes. GEOS diagnostics found no invalid feature or positive-area pair intersection in this snapshot. Ring closure/orientation, holes and native arrays remain untouched. No repair, discard, polygon coercion or curve densification is performed. Esri clockwise rings are considered shells only for qualified topology diagnostics; positive rings must actually be contained before being treated as holes. Orphans remain defects, never silently reinterpreted. Empty/null/curve/open/invalid cases remain preservable as demonstrated in negative fixtures.

`qa/native-topology.json` measures in source projected metres and square projected metres. These are not geodesic ground areas. A zero observed intersection result cannot certify legal completeness, gaps or slivers: no same-vintage signed legal outline was acquired. The service's November2023 descriptive update, layer template2022 and stale Hub2010 text remain separately recorded. Neither retrieval date nor matching names/counts establishes November2026 validity or a2024 results crosswalk.
