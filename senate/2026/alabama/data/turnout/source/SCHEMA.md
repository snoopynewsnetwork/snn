# Alabama original-first turnout schema

Owned outputs: `../../turnout.md`, `../county-turnout.csv` and this `data/turnout/` tree only. Paths in this schema are relative to the turnout tree unless stated otherwise. No Git, coordinator, newsroom or peer output is mutated by these scripts. Python 3.11, system Poppler `pdftotext`, requests 2.x, xlrd 2.0.2 and PyMuPDF are used. No dependency/cache directory is retained in the package.

## Original bytes and receipts

`source/original-receipts.json` copies the individual read-only shared SOS receipts and adds exact shared path, measured stored bytes and verification result. Original shared paths are workspace-root relative. All complete bodies were decompressed and SHA256 verified before any numerical preparation or peer derivative. The files named `*.html.gz` in shared news can contain PDFs; trust the verified body magic and response Content-Type, not the compatibility extension. Original PDF bytes include every page and unrelated contest; never replace them with rendered pages or extracted text.

`source/http/*.receipt.json` records each fresh requested/final URL, UTC start of retrieval, final status, response headers, redirect chain, original decoded entity-body bytes/SHA256, storage parts and parent context. Requests automatically decodes HTTP content-encoding. The stored original means that complete decoded entity body, not the transport-compressed bytes. Storage is independently gzip compressed with mtime zero. Concatenate ordered parts in receipt order and `gzip.decompress` to recover exact original bytes. No stored file reaches 40,000,000 bytes. The helper uses 30,000,000-byte ordered compressed-stream splits if needed; none of these fresh acquisitions needed splits. No truncation, repair or silent geometry simplification occurs. Existing shared compression is reused, not recompressed/copied.

`source/acquisition-qualifications.json` retains the initial restricted-network failures, API missing-key HTML, successful alternative, and a Census parent-context correction. A receipt's HTTP Date/Last-Modified is not an election count update or certification date. The Census reference was directly requested; the recorded execution-context SOS parent is explicitly not a claimed hyperlink. Current primary authority pages and linked original ZIP/PDF responses are retained in full.

`source/download-chains.json` separately pins actual linked child URLs to their complete parent-body hash and original HTML tag/line/column. A direct fallback remains explicitly unlinked. `turnout-rates.json` stores all 204 exact county/footer ballot-registration and absentee-ballot ratios, printed percentage strings and recomputation at their original precision. All printed rates agree; integer fractions remain the calculation inputs.

`source/original-first-witness.json` pins original hashes/sizes and each ZIP member's exact name, SHA256, bytes, CRC32 and source DOS timestamp. Prior witness bodies are frozen by hash in `history/` before later acquired sources are added. No numeric coordinator JSON/parser or peer derivative is an input.

## Raw extraction and visual evidence

`source/workbooks-2024.json.gz`, `workbooks-2022.json.gz` and `workbooks-2020.json.gz`: complete typed row extracts of all 67 original XLS members for each election. ZIP originals remain authoritative. Every sheet has literal name, xlrd dimensions, visibility, merged regions, 1-based row positions, raw padded string/numeric/empty values and xlrd type codes (0 empty, 1 text, 2 number, 3 date, 4 boolean, 5 error, 6 blank). Formatting can extend stored row arrays beyond the displayed data rectangle; all values/types are retained. All unlabeled header columns were tested for any populated data cell; none occurs. Unlabeled all-empty format padding is not a reporting geography. No unrelated-office derivative analysis is required: intact original members plus this unaltered row witness retain the context.

`source/sos-*-canvass-original.txt` and `sos-2020-ballots-original.txt` are complete unaltered `pdftotext -layout` output with form-feed page delimiters, accompanied by exact `.warnings.txt` stderr, including empty warnings files. Fresh PDF text/warnings use full original hash filenames. Some fresh signed certificates have no embedded text and extract only form feeds; inspected images, not invented OCR text, support their readings.

`source/visual/` contains complete original-page renders. `source/visual-transcriptions.json` pins original hash or receipt ID, PDF page, full render and normalized [left,top,right,bottom] region for each explicit reading. The 2024 Hale/Winston readings, 2022 Henry label and PDF blank/dash cells are explicit. Exact unaltered raw extraction remains alongside them. A transcription supplies a separate interpreted value; it never edits original bytes/text/images. Alias joins are explicit in build.py and raw labels remain in canvass-cells.json. The 2020 source uses an underscore-style St_ Clair separator; Census presentation joins explicitly to St. Clair. Native headers are never normalized or joined across years.

## Candidate, method and geography data

`candidate-universe.json` preserves every target contest row (including Under Votes/Over Votes when published), full literal contest/party/candidate strings, 1-based row, member hash and sheet. Each of all 67 workbooks contains exactly the actual five named presidential choices plus generic Write-In in 2024, the three named Senate choices plus generic Write-In in 2022, and the two named Senate choices plus generic Write-In in 2020. No candidate rows are deduplicated. Trimmed strings are used only for explicitly documented header comparisons/presentation. `NON` is retained as the published generic write-in party field; it does not identify a named eligible candidate. A legal named/valid write-in breakdown is unavailable.

`native-units-YEAR.json` is the complete descending reporting-column universe. Each unit has the exact native header, source member/sheet/1-based column, source election, county FIPS, literal row fields and numeric type/value. `native_id` equals the literal header because a distinct statewide precinct code is not supplied. The stable research key is `AL:YEAR:general:FIPS:colNNN:percent-encoded-header`. It is scoped to that source and election, not an assertion of a 2026 official ID. Slash-combined labels remain one actual source column. Identical/similar sites in different counties or columns are not collapsed. A header that looks like a church, municipality, ward, site or administrative group is not replaced with a county result.

The target `candidate_votes` array contains only named choices and generic Write-In; `reported_candidate_votes` is their integer sum. All candidate cells at labeled headers are numeric. `contest_other_fields` contains under/over rows, never votes in the priority denominator. `administrative_fields` separately retains registration, total/blank ballots and straight-party rows, including literal strings, raw value, nullable interpreted value and xlrd type. Missing field/row is null; printed numeric zero remains zero. Named/valid write-in allocation and current crosswalk are null, not zero. Unknown voting method stays unspecified. Method categories are explicit absentee, provisional, provisional+absentee or unspecified native precinct/site; the source spelling PROVSIONAL is retained.

`native-coverage.json` has all 67 parents per year with every constituent key and source member. These parents and statewide controls overlap the disjoint native leaves, so never add both. Administrative contexts have no assumed polygon. Current boundaries/IDs, method splits inside ordinary columns, legal write-in allocation and 2026 crosswalks remain unavailable. `source/county-fips.json` uses the Census county-code reference only; it does not imply VTD/precinct equivalence.

`canvass-cells.json` retains all 201 target county rows, statewide rows, complete raw original lines, raw labels, PDF page/text-line positions, target column positions/types, numeric token character spans and explicit visual overrides. Full source text retains adjacent office fields. The three PDF blank/dash cells stay null even though independently observed native zeros reconcile those scopes. `statewide-controls.json` contains the actual printed candidate controls; `candidate-reconciliation.json` lists all 871 county/candidate comparisons. Null PDF cells have no fabricated numeric difference.

## Ranking and separate sensitivities

`native-order-YEAR.csv` contains each whole native descending order and all weights/cumulative fractions. `native-rank-summary.json` retains every full-order, priority and remainder array, denominator, top-15 numerator, minimum 80% integer crossing and preceding count/votes. Order is descending candidate votes, then ascending complete key. Fractions use exact integer rational arithmetic; decimal percentages are display only. The minimum proof requires `5*preceding < 4*denominator <= 5*crossing`. A zero-vote source unit is retained in the remainder.

`priority-set.json` carries the complete 2024 native order, top15 keys, ordered 887-unit priority, all 67 parent/constituent/remainder arrays, administrative cases, full native records, source chain and unavailable cases. The original-first extraction closes the complete reported native candidate universe; no unavailable-parent substitution is used. The historical order's agreement with certified candidate controls does not assert that XLS columns carry a separate statutory native certification stamp. Source status is explicit. Actual independent_peer_agreement and coordinator_acceptance remain false, peer_agent_id null. Current 2026 geography/legal approval remains false. Downstream coordinator acceptance is separate from this reproducible historical measurement.

`priority-native-2024.csv` and `remainder-native-2024.csv` are the complete ordered primary subset and remainder; all keys are in native-order-2024.csv. No priority exclusion removes a unit from state arithmetic.

`../county-turnout.csv` is a 201-row parent sensitivity with 67 counties for each contest, candidate values, independent source ballot/registration/absentee controls, candidate rank/weight/cumulative values, native field known sums, missing under/over counts and source differences. Candidate_i positions are local to the named contest, explicitly named in each row; blanks after the actual universe are not extra candidates. County parents are not the native dispatch priority. `county-rank-sensitivity.json` retains full parent orders/priority/remainders for all three years.

`ballot-registration-controls.json` preserves complete 67 county rows and state footer for all three report vintages, all five integer statistics, printed percentage strings and raw lines/source-line positions. The report labels Registered Voters without an active/inactive split or precise registration extract date. 2020/2022 party fields explicitly mean straight-party ballots; 2024 says Democrat Ballots / Republican Ballots. Do not treat these as party registration or candidate totals.

`ballot-registration-sensitivity.json` contains separate county report-ballot, report-registration and report-absentee full orders. `native-ballot-registration-sensitivity.json` contains whole native ballot-field orders and the fully numeric 2020 raw registration-field sensitivity. Missing 2024/2022 registration cells prevent a complete native field rank; even 2020 raw registration is incomplete against report totals because many counties have published zeros. No raw native registration sensitivity is a certified full-registration priority. `source-discrepancies.json` retains county native/report differences. `field-audit.json` supplies every county method context, missing/zero-field coverage and all applicable within-unit arithmetic exceptions; neither candidate+under+over nor adding blank fields is imposed as a correction. Absentee and provisional labels do not prove acceptance or outstanding-vote status.

## Reproduction and sealing

Run from repository root, with temporary dependencies available outside the repository. Set PYTHONDONTWRITEBYTECODE to avoid cache artifacts:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=/private/tmp/al-turnout-deps python3 senate/2026/alabama/data/turnout/scripts/extract_originals.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/alabama/data/turnout/scripts/render_sources.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/alabama/data/turnout/scripts/build.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/alabama/data/turnout/scripts/field_audit.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/alabama/data/turnout/scripts/supplement.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/alabama/data/turnout/scripts/report.py
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=/private/tmp/al-turnout-deps python3 senate/2026/alabama/data/turnout/scripts/validate.py
```

Original acquisition is reproducible with scripts/acquire.py URL --parent AUTHORITY, using exact URLs in each receipt. Reacquisition is a new timestamped observation, never an overwrite of a previous body. Do not run it for offline validation. Decompression and Poppler temporary PDFs use the system temporary directory, not repository caches.

`freeze.py` saves each prior owned body as lossless content-addressed gzip plus origin/size/hash metadata before any replacement. History bodies are immutable; a recreated identical file is not rewritten. This includes earlier scripts, witness, validation/seal/report versions if any. Final asset membership excludes only asset-manifest.json itself. Validation and seal do not contain a manifest digest, eliminating reverse/self hash cycles.

After validation, scripts/seal.py writes final-seal.json then asset-manifest.json LAST. No further writes occur. `validate.py --audit` reads the sealed manifest and all files, verifies exact membership, path containment, SHA256, size bounds, external original references and absence of dependency/cache directories. It does not rewrite validation or seal. Rebuilding a sealed package is a new version requiring preservation, revalidation and resealing; ordinary read-only QA uses --audit.
