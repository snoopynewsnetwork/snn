# Official-results evidence and replay

Owned scope is exactly `../../official-results.md`, `../official-results-sources.csv`, and this entire directory. External acceptance is PATH ONLY at `data/coordinator-priority-acceptance.json`, state-relative. Its body/hash is never copied or reverse-pinned. The exact contract pin is allowed and retained in script constants and context references. Producer flags and every external source remain untouched.

`http/*.receipt.json` are individual immutable observations. Each request includes method, complete URL, form fields if any, configured headers, actual per-hop request headers/body, UTC retrieval start/end, final/error classification and every returned hop/status/header/body. `body.parts` are complete ordered gzip-stream pieces, each strictly below 40,000,000 bytes. Verify each stored part, concatenate in order, decompress once, then verify whole entity bytes/SHA. Requests-decoded entity bytes are distinct from HTTP transfer/content encoding. Empty observed response bodies have genuine zero bytes; a no-response failure has no fabricated response status, headers or body/hash. Per-hop timing beyond overall start/end is unavailable. Source Date/Last-Modified/cache/printed/run clocks are never retrieval or certification clocks.

All `*-jobs.json` and parent evidence preserve exact observed anchors or client constructors/options. `mobile-request-constructor.json` keeps every option and complete GET field list. The public default plus three bounded scopes retain every contest/object in `complete-public-json-samples.json`, as well as exact original response bytes. No scalar projection, null-to-zero conversion, numeric alias, precision reduction or silent text repair is applied. Inline source code/runtime and source headings/options/links remain in each parent observation; source code is evidence, never executed.

`directory-records.json` has all 278 original role records including repeated counties/office divisions. Field labels/values, blank strings, positions and source links remain arrays. County trimming is a presentation join only; `county_raw` and original bytes survive. Every one of all 67 parent objects embeds its complete office observations, full original source-member chain and qualified bounded local investigation. Failed/stale/local-only/history/setup channels remain distinct. No nonexistent current feed is invented for a county. Outside-priority Conecuh, Greene, Lowndes and Washington retain the same full historical statewide coverage.

`historical-hierarchy.json.gz` is one lossless whole JSON entity. Its 2,085 records each reference the complete external own native object by contract pin/pointer/semantic hash, retaining candidate/header/party/null/method/admin/context through that full object. All 67 full parents carry complete original object references, full source-column order and statewide-rank order, and priority/remainder arrays in each relevant order. It is not a county substitute. Current matches, IDs, CRS and vintage are null; approvals false. The raw external contract, not a newly discovered helper or aggregate, reconstructs complete objects. Full baseline scenarios/targets/CLI/outcomes are outside official-results equality, even though whole companion/history bytes remain verified as authority.

`original-references.json` reuses individually pinned complete originals read-only. `replay_originals.py` independently uses xlrd 2.0.2 from `/private/tmp/al-turnout-deps` to reopen all 201 original BIFF members and every cell. It never imports a producer. `replay_authority.py` consumes the entire acceptance in memory, checks full pins, whole recursive semantics in original traversal order and complete retained archive members, including old path/body versions. A newer body at an old path cannot substitute for an archived member. `history/` preserves complete failed checker/parser versions and old bodies. Invalid fixture/history inputs remain history, never current observations.

`pdf-index.json` points to whole original PDF entities in HTTP receipts and complete unmodified `pdftotext -layout` stdout, stderr and pdfinfo output. Text artifacts are gzip compressed once. `visual/` holds full-page renders; manual-readings explicitly identifies pages actually inspected, full source/render hashes and page regions. Other pages received complete text/source replay only. Blank/form-feed-only extraction is not invented OCR. Printed ballot observations do not exhaust later signed certifications or eligible named write-ins.

Final order is validation, final-seal, manifest LAST, then `audit.py --audit` with no owned writes. The manifest scope excludes only itself; validation and seal do not hash the current manifest.
