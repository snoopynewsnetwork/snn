# Massachusetts offline map package

Open [index.html](index.html) directly. Search/filter all2,394 literal historical result contexts, 1,470 priority/924 remainder, all351 parents and full child orders. Parent pages link complete source objects, municipal chain records, native coordinate previews and acquired map PDF receipts/renders. The atlas has no network dependency and assigns no votes to geometry.

Start with [SCHEMA.md](SCHEMA.md), [source-index.json](source-index.json), [manifest.csv](manifest.csv), [reconstruction.json](reconstruction.json), [native-audit.json](native-audit.json), [PDF index](pdf-index.json) and [visual scope](visual-review.json). Raw entities are complete deterministic gzip, with exact ordered splitting when required; reconstruct with `scripts/reproduce.py`. Existing complete producer originals remain read-only at their state-relative paths, individually pinned by `readonly-inputs.json`. External acceptance authority is path only, never copied or reverse-pinned.

Use the commands in SCHEMA for offline replay and verification. [validation.json](validation.json), [negative-fixtures.json](negative-fixtures.json), [replay.json](replay.json), [final-seal.json](final-seal.json) and [asset-manifest.json](asset-manifest.json) describe the completed package. The manifest excludes only itself. Every stored file is below40,000,000 bytes; no source geometry was rounded/reprojected/repaired. Current/legal/native result-ID matching, exact eligible write-in coverage and live returns/cadence/outstanding pools remain unapproved external qualifications. Coordinator alone accepts and publishes.
