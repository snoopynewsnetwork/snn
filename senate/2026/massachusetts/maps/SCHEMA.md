Authority is **PATH ONLY**: `../data/coordinator-priority-acceptance.json`. It is read completely at replay, never copied or reverse-pinned by this package. The frozen `../data/turnout/priority-set.json` is preserved as the complete 25-root source object in `contract.js`; producer flags are unchanged. `scripts/reconstruct.py` independently checks every root semantic digest, all 174 complete JSON/CSV companions, all 397,917 recursive objects in all three complete gzip JSONL partitions, every 781 producer-sealed asset and every listed original dependency. `readonly-inputs.json` freezes those individual finished dependencies. It does not rely on the appendable news aggregate, an unfinished peer, or an optional coordinator review. `reconstruction.json` records the result. Files remain materializable recursively through `scripts/reproduce.py --historical-file PATH --pointer JSON_POINTER`; a CSV file materializes as every raw row/cell including headers. No vote-only projection replaces an original.

`inventory.json` contains all 2,394 complete ranked source objects, all 351 parent records, complete original source order, canonical rank, 1,470 priority and 924 remainder arrays, and all original contract parent objects. Each `units[].full_source_object` equals the corresponding complete contract object, including raw row, ordinal, nulls, method/admin/control values. Each parent contains independently reconstructed source/rank/priority/remainder children. Its `municipal_chain` is a display summary with a path to the complete chain object under `parents/`; every full chain retains all extracted text and literal href attributes as well as original response locators. The display summary does not substitute for those complete bodies. `atlas-data.js`, `contract.js`, `gis-objects.js`, `atlas.js` and `index.html` operate from `file://` without network, a server or dependencies. Full parent chain JSON is linked separately to avoid duplicating large HTML-derived text inside the index. HTML rendering uses `textContent`; JSON script encoding escapes `<`, U+2028 and U+2029. Parent filters, both source/rank orders, scopes, fullobjects and DOM event execution are checked by `test_atlas.cjs`.

**Identifiers are source scoped.** `native_key` is the exact `[City/Town,Ward,Pct]` string tuple in one historical contest. Numeric counts, GIS OBJECTID, MassGIS TOWN_ID, Census GEOID, municipal display names, ward groups, precinct names and polling places are separate. No native result numeric ID/GEOID is supplied or manufactured. Expansions of the PD43 `N./S./E./W.` municipal abbreviations support directory discovery and municipal preview search only. They do not establish result-polygon or cross-year equality. `geometry_match`, `numeric_native_match` and `physical_match` stay null and current approval stays false. Complete 2022 historical empty-Ward/Pct municipal cases remain in source companions without invented physical precincts. No municipal sensitivity dispatch substitute or name/spatial vote allocation is made.

`receipts/*.json` stores exact requested/final URLs, GET query and null request body, source parent/literal href when available, UTC retrieval clock, status/errors and every observed redirect exchange, complete request/response headers, and raw/stored byte hashes and lengths. A web-tool navigation target is explicitly a representation, not the missing original HTML literal href. Raw entities are the complete transport-decoded response bodies; no claim of TLS/wire packet preservation is made. HTTP200 challenge shells and non-map bodies are retained without map/vote/currency credit. `web/*.txt` preserves research-web representations and exact failed-link observations, not original document bytes or browser screenshots. `municipal-directory.json` retains all 352 directory entries/351 distinct names, including duplicate Harvard and the inconsistent Lynn homepage link; it does not repair raw directory fields. The coordinator preparation's giant encoded-state regex candidate was rejected; its preparation is not a build dependency. Actual own hub __SITE/runtime/public portal search established the service IDs without stripping the thumbnail suffix.

`originals/` is content addressed. Each original body is stored once by raw SHA-256, using deterministic lossless gzip. When compressed bytes are at least40,000,000, the one gzip stream is split into exact ordered parts of at most39,000,000 bytes. Reconstruct by concatenating receipt `parts` in order and gzip-decompressing; verify every stored part and whole raw length/hash. Several incidental non-map bodies were retained, including a large public election-information audio file and a historical register reached from clerk navigation. They receive no map, geographic or current coverage credit. Repeated requests reference the same body rather than duplicating it. The Medford map original also requires splitting. `source-index.json`, `original-index.json` and `manifest.csv` inventory full requests/entities; `scripts/reproduce.py --receipt receipts/NAME.json --output /private/tmp/original.pdf` reconstructs exact originals. No giant response is called acquired without all its bytes retained. All owned stored files are strictly below40,000,000 bytes.

`wards-layer0-acquisition.json` and `subprecinct-layer0-acquisition.json` preserve exact IDs/counts and each requested/returned batch array. Metadata/count/all-ID queries occur before and after, with full raw bodies. Each batch has at most50 exact observed IDs, `outFields=*`, geometry, Z, M and truecurve returns enabled. There is no outSR/outputCRS, rounding, quantization, precision, generalization or repair. Native CRS is EPSG26986, NAD83 Massachusetts Mainland, meters. `native-audit.json` records observed installed Shapely/GEOS versions, `from_wkb` constructor implementation/source and all ring diagnostics. Every linear ring must already be bitwise closed and finite before manually packed WKB is parsed. Clockwise exterior and counterclockwise hole orientation, containment assignments, orphan/zero-area/invalid status and double-bit digests are diagnostics separate from complete raw native rings. No `Polygon`/`LinearRing` constructor silently closes/reinterprets source rings. Truecurve input is preserved and excluded from linear-only topology; no curves were observed in these snapshots. No native Z/M ordinates were invented. Two invalid ward features remain unrepaired. Positive-area pair diagnostics are in square meters, without an operative outline and without legal overlap/sliver/gap certification. `ZIP-container-audit.json` independently tests every acquired ZIP container's full CRC/member list; these are office-document files, not SHP ZIPs. No original SHP ZIP was acquired from an actual accessible link, so full DBF/SHP/SHX/every-XY-bit comparison against an installed SHP parser is explicitly **not claimed**. Native service JSON is the acquired GIS original.

`previews/*.svg` contains all native linear vertices for each municipal display-name selection, using only an affine vertical reflection and SVG viewport scaling. Coordinates are serialized with round-trip doubles, without projection/rounding/simplification. There is no legal outline, vote shading or result-row polygon assignment.
