# Massachusetts official-results evidence schema

This directory is the official-results worker's exclusive package. All paths
inside JSON are relative to this directory unless explicitly `state-relative`.
The external historical authority is **PATH ONLY**:
`data/coordinator-priority-acceptance.json`, relative to Massachusetts. Its body
and digest are not copied or reverse-pinned. Historical source identity never
establishes a current municipality, precinct, candidate, method, or feed ID.

`reconstruction.json` records an independent read-only replay of all 25 roots,
174 complete companion bodies, all 397,917 complete recursive objects in all
three complete gzip JSONL partitions, every 781 producer-sealed asset and its
original inputs. `readonly-inputs.json` freezes those individual state-relative
dependencies. No producer module/writer, appendable newsroom aggregate, maps
worker, or optional coordinator review is a build dependency. Every referenced
original remains at its immutable shared path. No original is copied merely to
make a second large body.

`parents/001.json` through `351.json` contain complete bounded authority
investigations. Their numbers are **research ordinals**, never native IDs. Each
contains the complete frozen municipal parent object and its source/rank child
arrays, literal name, Secretary directory representations, exact fragment
offsets, distinct clerk/commission/registrar/precinct-canvass/state-certificate
roles, all attempted source receipts, observed literal links, scripts/form
references, sample structures, publication wording, and explicit access gaps.
`priority_parent=false` means inventory coverage rather than an assertion of
an independently investigated current precinct service. All 351 remain present.

`priority-investigations.json.gz` has **exactly 1,470** records in the accepted
historical rank order. `remainder-investigations.json.gz` has **exactly 924** in
the corresponding remainder order. Every record contains the complete frozen
order object, complete original source record (including raw row, header-related
values, literal tuple, source ordinals, candidate/generic/blank/control counts,
method/admin/numeric-ID nulls), a specific shared-parent reference, and current
admission fields left null/false. This is 287 shared priority municipal chains,
**not 1,470 independent leaf feeds**. `all-unit-index.csv` locates every one of
the 2,394 records. `all-parent-hierarchy.json.gz` retains all 351 complete parent
objects and full/priority/remainder global arrays. The original frozen contract
and replayable companions additionally preserve every raw source/priority/
remainder child grouping, 9,351 native + 1,404 municipal records, 75,566 numeric
positions, 32 baseline + 24 turnout orders, and 36/36,702 state/unit scenarios.

`data/official-results-sources.csv` is outside this directory, still exclusively
owned. It contains 351 municipal research-parent rows plus four state/federal
publication or certificate/contest authorities. Blank current-ID/clock/pool
cells mean **unknown**, never zero. Full directory text and role occurrences are
JSON strings, not flattened into a single assumed clerk. CSV paths resolve here.

`municipal-government-directory.json` reconstructs all 2,638 numbered lines of
the Secretary's web-extracted government directory. It retains the duplicate
Harvard heading, footer heading, source misspellings, printed contact fields,
domain labels, and observed blanks. It is **not original HTML**. Literal href
attributes are unavailable where the web tool only displays citation/domain
labels. `directory-navigation.json` records actual department/home link clicks,
including errors that reveal no destination URL. Florida, Hawley and Heath have
no department link in the observed government listing; Monroe has no website
link there. No URL was manufactured to fill those gaps.

The separate Secretary **local-election-office** directory returned HTTP403.
Targeted searches cover all351 parents; indexed fragments are retained exactly,
with pointer/character offsets in each parent. They may omit material within an
entry. They do not supply complete raw HTML fields/hrefs or establish that an
unseen field was blank. Missing original fields remain unknown. An explicit
directory role line is distinguished from a legal functional responsibility.
`raw_field_completeness=false` is deliberate. A malformed/partial indexed entry
is never repaired using another municipality's phone, address or role.

`source/http/*.json` retains request method, exact requested URL and query,
request body (GET means null), parent and literal href when actually known,
retrieval UTC, every redirect hop with request/response headers and full entity,
final URL/status, exceptions and source-clock qualifications. Self-redirect
attempts and subsequent ordinary-cookie HTTP403s remain distinct. Initial
unverified relative-href metadata was corrected to null with a correction note;
requested URLs and response bytes were unchanged. DNS/TLS/timeouts are errors,
not HTTP403. A denied redirect or policy exclusion is not an issued request.

`source/byhash/<raw-entity-SHA256>.gz` stores every complete response entity once
by hash, including redirect/challenge/error/empty bodies. “Raw” means the full
requests transport-decoded entity, **not original compressed HTTP wire bytes**.
Receipts specify raw/stored hashes and byte lengths and lossless compression.
No source body is truncated. Each stored artifact is strictly below40,000,000B;
oversize entities use exact ordered raw-byte splits with each part losslessly gzipped. The earlier Lynnfield oversize capture errors remain explicit; a separate bounded retry retained its complete71,566,477-byte original in three parts. Those earlier response bodies were not recoverable as earlier snapshots.
No auth/admin/account/password/social/email route is fetched. `source-scope-negatives.json` is a manually reviewed list of unambiguous other-municipality search attributions; their raw evidence remains, with role/publication observations excluded from the wrong parent. Abbreviated municipal domain names were not mechanically treated as mismatches. Public links to
such paths can remain in original source bytes without being visited.

`source/inspect/*.json` is an automated complete text/link/form/script extract,
not a browser rendering. `source/search`, `directory-search`, `navigation` and
other web JSONs store the **complete returned web-tool representation** with
query/click context and UTC. A source's stated total line count can exceed the
window returned by that tool; this is not a claim of full raw-page capture.
All source originals actually retrieved by HTTP are separately materializable.
The optional in-app browser was unavailable and browser inventory showed no
enabled browser surface; no browser-rendering claim follows.

`source/structures/*.json.gz` and `structure-index.json` materialize full
response samples. HTML preserves every table/cell ordinal, tag, attributes,
raw text, present blank, forms/options, meta elements and complete inline script.
JavaScript retains complete text and constructor/call offsets. A CMS search,
translation timer, WordPress admin URL, or Cloudflare challenge is not an ENR
constructor. None of those scripts is executed. JSON preserves the **whole
envelope**, arrays, administrative/filter/pagination fields, party/name/content
fields, nulls, source clocks and nested HTML tables, never a vote-only projection.

The Abington public Apptegy/Thrillshare config is decoded from the actual
`JSON.parse` string and retained whole in `observed-public-configs.json`. Its
literal public news/live-feed URLs are sampled once. The two complete responses
have20 rows each and full `meta`/pagination/filter objects; they are bounded
page samples, not the whole CMS. `last_static_update` is a CMS clock. Article
`published_at` offsets are publication metadata, not measured count cadence or
correction/completion clocks. CMS organization/section/article IDs are not
November contest/candidate/reporting IDs. Social flags and author-null fields
are retained as data, without sending anything to those services.

PDF structures contain complete all-page `pdftotext -layout` output, page
boundaries, extraction return code/stderr and scan/text gaps. Text extraction is
not visual proof. XLSX structures contain every ZIP member's identity and hash,
and recursively complete XML/rels trees including all cells/positions, shared
strings, formulas, styles, blanks and properties. Missing cells remain absent;
cached values are not recalculated or promoted to counts. CSV samples retain
every record including both ragged header/party rows and state controls, every
raw string, record lengths and column positions. An absent party-row position
is null with `party_position_exists=false`; a present empty string stays empty.

`source/reused-original-receipts.json` freezes individual immutable historical
receipts without relying on their former mutable newsroom aggregate. Exact
original bytes remain read-only at the stated paths. All Others, named
write-ins, party display, blank, total-cast, method, admin and null fields remain
distinct. The2022 118 sole empty-Ward/Pct source records stay municipal-level;
the county HTML discrepancy and2020 Shiva/2024 Sonski-West metadata differences,
supplemental +33/-64 and347-registration/missing4/six-county/403 controls are
preserved through the complete replay. No registration-minus-count pool,
native allocation, coalition, eligible write-in allocation or legal80 approval.

`source/previews` are separately labeled automated PDF raster derivatives.
`visual-qa.json` identifies precisely the three pages actually viewed. Other
PDF pages were automatically extracted, not visually inspected. Sample ballot
images establish bounded printed metadata only; they do not approve a signed,
exhaustive final/later/write-in roster or a current geographic crosswalk.

`legal-findings.json`, `current-qualification.json`, and the report distinguish
law text, effective dates, nominal/adjusted calendar calculations, older rules,
primary-specific advisories, actual judicial orders, later/exhaustive gaps, and
Senate-specific authority. No legal/calendar/roster/feed exhaustion is claimed.
`fixtures.json` and `validate.py` exercise meaningful negative admission and
remaining-pool cases without creating real returns or a collector.

`validation.json` includes source, schema, full hierarchy, sample envelope,
strict-size and negative-fixture results. `final-seal.json` pins report/CSV and
validation without a reverse manifest pin. `asset-manifest.json` covers EVERY
owned file, including validation and final seal, and excludes ONLY itself.
The final sealed validator is read-only. No hash cycle or hidden exclusion.
