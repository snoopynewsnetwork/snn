# Idaho official research schema and source semantics

All owned JSON is UTF-8; raw HTTP entities retain their native encoding. Gzip reconstruction is exact. CSV directory content is decoded as Windows-1252, with no trimming, imputation, renaming or blank-to-null conversion. All original columns remain in `directory-native.json` and each inventory row's `directory_native_json`; the empty column name and empty strings remain literal. The added state inventory row has blank directory-person fields because it is not a county directory row.

`receipts/<id>.json` is immutable acquisition metadata: request URL and method, parent/href or inline constructor/observed argument evidence, retrieval/finish UTC, redirects/full headers, response status, complete stored entity identities, or exact transport failure with no invented response. Raw bytes refer to the complete requests entity representation; `Accept-Encoding: identity` was requested. Wire content-encoding/length remain in response headers. Content-addressed `.gz` storage deduplicates equal entity bodies, not observations. Receipt `id` is a researcher observation name, not a publisher contest ID. In particular `bill-S1356-status` is the acquired SOP PDF; `bill-S1356-final-status` is the actual bill history page and says its daily-journal-derived status is unofficial. Do not infer document authority from observation filenames.

The451 observations include old primary, public navigation/configuration, current law/instructions, failures and researcher mistakes. All acquisition IDs are enumerated by `source-index.json`. Source completeness, identity, semantics and scope must be inspected; HTTP status alone is insufficient. The initial33 election-UUID export attempts and two malformed Gem URLs are explicitly researcher errors. Actual source failures include challenged pages, DNS/TLS errors, the old handbook404 and distinct shells/maintenance pages. Current public app primary flags do not admit a November contest.

The native result response keeps the full object graph. `public-response-schema.json` uses JSON-pointer-like paths with `/*` for array positions and records all observed Python JSON type names; it is an observed shape, not a guarantee of future responses. Objects retain multilingual text arrays, parties, complete election/jurisdiction metadata, source clocks, flags and nulls. `ballotItems[].id` and `summaryResults.ballotOptions[].id` are UUIDs; option `nativeId` corresponds to an export Choice ID where demonstrated by the actual same-primary body/export, while export Contest ID is a separate field. Candidate names, filing-search IDs, DOM IDs, GUIDs, historical keys and map-feature IDs are never automatically joined.

Metadata `asOf`/`lastUpdated` useZ where supplied. Null `nextUpdateAt`, `countGroups`, under/overvotes, group results, missing administrative fields and empty arrays are preserved literally. `precinctsReporting` and reportingStatus fields are native completion descriptions, not percent of votes counted. `isOfficialResults`/`isProduction` and fully-reported values retain their primary scope. No primary enum integer is relabeled as a current approved status. Source `ballotItemCount:1` differs from actual returned-array cardinality; the state zero-ballot metadata differs from county nonzero fields. These are retained, not silently reconciled.

Full XLSX extraction records every ZIP member name/CRC/size, shared string, sheet name/member/attributes, row number/attributes and cell address/value/type/style/raw_v/formula. Blank strings and nulls differ. Original ZIP XML/styles remain in the retained entity even where not projected into the extraction. All original export rows and cell metadata are independently checked. PDF extraction records complete text and page boundaries, not an exhaustive representation of graphics or struck-out law; full PDF originals and the selected visual witnesses preserve those meanings.

`historical-source-graph.json` contains complete individual file pins and full-byte/reconstruction/semantic identities, all42 original contract root fields, and5,169 complete object references (44 parents +985 presidential native +3946 distinct historical native +194 admin/control objects). Each pointer references a complete object, including original labels, rows, candidate/null/method/unavailable meaning. Every actual acceptance-listed companion body is required:20 turnout paths and9 baseline paths. These may overlap controls and are never additive observations. The external acceptance is referenced by path only and never hashed or changed by this package. Worker flags remain false. Frozen producer provenance can mention old optional/aggregate documents without making those mutable paths build dependencies.

`parent-investigations.json` has45 authority entries;32 county entries contain acquired full native export references. Every county preserves the full metadata and actual native primary counts, complete primary Senate item/choice objects, raw evidence references and county-specific findings. Native counts are source scopes, not historical/current crosswalks.

`priority-investigations.json` has exactly528 entries in accepted descending candidate-total/lexical-full-key order. Each entry has a full historical object pointer+semantic identity, source-row bounds, literal label/method flag, order record, parent-analysis pointer, all acquired shared-parent source refs, specific finding and exact finer-entry gap. Its `current_leaf_id`, `current_contest_id`, `current_choice_ids`, `current_method`, `current_geometry` remain null and `current_approved:false`. `remainder-monitoring.json` has the457 ordered remaining identities with all44 coverage retained. `all985-hierarchy.json` preserves every parent/child/priority/remainder map. Historical keys are source identities, not physical precinct approval.

The denominator is2024 presidential **11 named candidates/write-ins905057**; over/undervotes remain separate. No Idaho2024 Senate surrogate,13-county sensitivity replacement, residual null fill, Boundary allocation, Bingham statistics-only presidential inference or2022 HTML stage attribution is permitted. All source/footer/appendix/control bodies, candidate/header/party/raw fields, five ABS lexical differences and six earlier tie histories remain preserved through complete immutable references and independent semantic/source-cell checks.

`current-candidate-scope.json` is the bounded2026 Twin Falls LD24 sample's printed roster, not statewide signed certification, eligible-write-in exhaustion or result IDs. Complete historical candidate vectors remain separate. Current law and source-qualified uncertainty are in the report; requests/envelopes/ballots/accepted votes/contest totals and legal outcomes never collapse into one quantity. `current_approved:false` throughout is not a pending historical extraction task: it expresses external current-source/roster/geography qualifications.

`manifest.json` lists exact owned paths below the assigned subtree plus report/inventory, with SHA256/bytes and reconstructed identity for gzip. It includes immutable external complete references separately and only the external acceptance path. Every stored object must be strictly<40000000B. Its own file is excluded from its membership list to avoid a cycle. Read-only final validation checks exact membership, every owned/external identity and offline output reproducibility after sealing.
