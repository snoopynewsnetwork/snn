# Idaho turnout sources and schema

Primary dispatch is **2024-11-05 presidential candidate votes across 985 literal source county/Precinct contexts**. County summaries are sensitivities. `county-turnout.csv` is a compatibility filename for genuine 44-county parent summaries and does not replace native reporting identities.

Run `python3 data/turnout/build.py`, `python3 data/turnout/pdf_checks.py`, `python3 data/turnout/finalize.py`, `python3 data/turnout/validate.py`, `python3 data/turnout/asset_manifest.py`, then `python3 data/turnout/validate.py --verify-assets` from the Idaho directory. Builders use the retained originals and standard Python; PDF checks also require Poppler `pdftotext` and `pdftoppm`. No dependency/cache directory is retained. `acquire.py ID URL [PARENT]` is the separate public acquisition tool and requires requests/network. Offline reproduction does not download.

## Original bytes and authority

`reused-originals.json` pins the unchanged originals in `../../news/` relative to this directory's parent `data/turnout/` (each record's `reused_path` is relative to `data/turnout/`, normally `../news/...`). These original downloads are retained once, gzip-compressed losslessly. Verify stored SHA256, decompress, then verify original byte length and SHA256. Original ZIPs contain complete original workbook/PDF member bytes, including unrelated contests and county abstracts. `archive-members.json` supplies member SHA256/size/CRC32. No county abstract is additive to its included statewide workbook.

`requests.json` retains newly acquired requested/final URLs, redirect history, HTTP status/headers, UTC retrieval, raw/stored hashes/sizes and parent routes. HTTP 200 is not proof of substantive content: `timezone-law.gz` is the retained eCFR challenge, explicitly not authority for the boundary. `timezone-govinfo.gz` is the successful official 2025 CFR alternative; its revision date is separate from 2026 retrieval. `results-current.gz` retains the actual May-primary presentation and direct archive hrefs. The archive download headers' Last-Modified dates are server object clocks, not canvass certification or vote-count update clocks. No changing election-night sequence is observed.

`reused-national-originals.json` pins existing New Hampshire question assets read-only by exact hashes. Its paths are relative to `senate/2026/`. Full original acquisition metadata and response header files remain at those referenced paths. `pdf_checks.py` independently extracts their original PDFs; it does not use that peer state's derivative counts. These are national primary source controls, not Idaho geography allocations.

## Identities and nonadditive hierarchy

County FIPS come from the Census national county 2020 code table, compared to the exact 44 Idaho county names. These identify counties only. Native context key `ID:2024:pres:<FIPS>:<first original race row>` is an analytical source-position key, **not an invented official precinct ID**. Preserve the raw Precinct field, including leading zeros, numbers, names, and administrative labels. Numeric labels have only their published source scope; they do not establish cross-year identity. No polling-place identity is supplied. A precinct name, polling-place address, municipal parent, ballot style, VTD or current polygon is not interchangeable with this key.

`native-2024-president.csv` is source-context inventory; `native-order.csv` is the complete descending order with integer cumulative votes, exact weight numerator/denominator, and minimum80 flag. Ties use full source key ascending Unicode lexical order after descending votes; row text is a string in this key. No tie spans the 527/528/529 crossing. `native-2024-candidate-positions.csv` supplies each source category row/G cell, raw party/name, integer value and role. `native-2024-stats.csv` has independent stats keys and source positions. Its literal pairing with a presidential label is explicitly **not approved as identical physical/method scope**.

`historical-native.json.gz` and `historical-candidate-positions.json.gz` retain native rows/candidate cells by year/contest/book/sheet/row. Historical county headings and continuation syntax establish only within-workbook parents. `historical-county-candidate-controls.csv` contains independent county controls and overlapping footer positions. `historical-administrative-controls.json.gz` retains county footers and post-county control/appendix roles without allocating them to the last county. Final 2022 governor row 1157 literally `CO. TOTAL` is statewide, not an extra Washington precinct. The 2020 state/district/Ada appendix and 2022 Senate GRAND TOTAL are likewise nonadditive. `native-2020-stats.json.gz`/`administrative-2020-stats.json.gz` retain statistical rows separately.

`method-label-inventory.json` flags literal Abs/Absentee/Early/Mail/Provisional/Central words as a search aid only. It is not a complete method partition: numeric/geographic rows may already include absentee/early ballots. Keep every flagged/unflagged context, including zero-vote contexts. No operational method, polygon or source electorate is inferred from the label.

## Priority contract and arithmetic

`priority-set.json` schema `idaho-turnout-2` has primary full985 order, ordered528 priority keys, explicit457 remainder keys, and all44 parent objects. Ordered full/priority/remainder child maps partition the same985 keys by county. Parent grouping is nonadditive: never add county totals to children. County top15/minimum13/union15 remain under `county_sensitivity`. `source_object_paths` references every detailed candidate/stat/method/admin/null source object; full source-native constituents are embedded by parent and pinned to original positions. Exact 80% check is `5*cumulative >= 4*state_total`, with predecessor failing. `native-rankings.json` includes source-scoped alternative ballot/registration/midterm orders; no cross-year native join is asserted. All remainder votes remain in denominators.

Blank/under/over fields not published for a historical contest are unavailable, not zero and not ballot-minus-candidate residuals. `field-availability.json` makes those availability scopes explicit. `source-observations.json` records source vintages/status/chain and current-display qualifications. CSV empty fields represent null/unavailable, never an inferred numeric zero; raw source derivatives retain present-empty/absent distinctions.
