# Independent original-first extraction

Before any turnout numerical derivative, extract.py parses only retained original OOXML/JSON/PDF/HTML bodies and their acquisition receipts. source/original-pins.json embeds complete receipts plus immutable original/stored SHA256, size and repo-relative path. Reuse is read-only; no huge original is duplicated. Exact bytes are gzip-decompressible. Failed requests are retained. Re-extraction checks stored hashes. The raw originals preserve unrelated contests, object member order, source nulls and literal field names; no demographic derivative is required.

candidate-records.csv.gz contains positional selected-contest candidate rows for separate 2020/2022/2024 API and FullData lanes plus 2024 XLSX. API state/county/county-native-response/native are overlapping views and must never be added together. FullData county-wrapper is a repeated precinct wrapper, not a disjoint county footer; only native may be grouped within a contest. FullData positional native_id is a source-array address, never an electoral ID. XLSX native_id null; literal county + precinct is its identity. Each source position links to its original body via source_id. Party literals remain raw: partyID1 is not a party inference. Null and empty literals remain distinct in raw originals and JSON controls (CSV empty serialization alone is ambiguous).

source/xlsx-president-rows.jsonl.gz preserves every selected row/cell reference, raw type/value and decoded shared string in original row order. Numeric values are integer votes; method totals are additive only after reconciliation, never overlapping All plus components. source/contest-controls.json.gz retains complete node fields including choice metadata and nulls, omitting only child geography subtrees, each separately extracted. source/native-inventory.json retains exact info hierarchy and IDs, with all raw constituent fields. source/candidate-metadata.json retains entire selected contest metadata and all returned party/vote-type definitions. source/turnout-controls.json retains full 225 responses including source statewide envelope, county response, empty native locations, raw registration and ballots definitions/status/clocks. No native turnout zeros inferred.

source/independent-rankings.json independently sorts each lane/level/contest by decreasing complete candidate votes then literal county ID/native key. Exact integer priority crossing: preceding cumulative*5 < statewide*4. Source-native identifiers and order are separate publication contracts; matching names or vectors do not establish geometry or crossyear identity.
