# Arkansas maps schema and reproduction

Owned scope is `precinct-maps.md` and `maps/**` only. No Git, producer/source flag, README, coordinator or other assignment writer is used. Authority is the path `../data/coordinator-priority-acceptance.json`, consumed whole in memory; its body/digest is never copied, pinned or reverse-linked by a digest. The complete frozen turnout contract is independently pinned. Historical source roles retain exact individual whole bodies/receipts/archive members with role-specific references; all archive members remain in their original complete archives.

`originals/<label>/receipt.json` records literal request URL/method/body/fields/configured headers/parent, actual UTC start/end, complete curl metadata/stdout/stderr and availability. `body` and `headers` separately give original bytes/SHA plus ordered stored parts and their bytes/SHA. Concatenate parts in listed order, then gzip-decompress exactly once. No part or response body is truncated, projected or normalized. Every stored file is strictly below 40,000,000 bytes. `response_body_available=false` and `body=null` describe actual no-body failures; HTTP0 in curl metrics is not a server status. Every response header block remains separate from retrieval times/source clocks. Initial two redirect probes lack intermediate bodies; their limitation/old script is history and new whole-hop requests retain the observed 302 empty body and destination 200 body separately.

`original-catalogue.json` includes every complete acquisition receipt and its own exact receipt pin. No producer builder is imported. `source-roles.json` inventories individual complete frozen source/companion/original/receipt/archive/member roles, independently checked from the path-only authority. It does not pin or copy the authority. No current mutable news ledger, producer helper/directory discovery, unfinished official package or optional coordinator build supplies maps.

`derived/<FIPS>.esri.json.gz` contains the complete source-native features selected only by returned literal county_fips, native envelope/fields/CRS and exact original page pointers/receipt references. JSON remains Esri JSON; `curveRings` and all control values are retained. No GeoJSON conversion, output CRS, numeric precision reduction, simplification, quantization or repair is used. Original lexical number tokens remain in complete original page bytes. `native-inventory.csv` is a convenience index; exact null/empty distinction and every field/geometry remain in the complete originals and native assets. `manifest.csv` inventories all 75 county assets with exact stored size/hash/vintage/CRS/count/qualification.

`parent-investigations.json` has one substantive source-backed investigation per historical parent: full/priority/remainder child arrays, complete returned county-native IDs and labels/codes/VTD/edit fields with original page pointers, count/ALLIDs controls, duplicate-label and curve inventories, native asset and explicit identity/current/administrative gaps. Historical key arrays and all source-context objects preserve source order. No association joins a native GIS feature to a result observation. `historical-order.json` records exact state and parent full orders; atlas row details contain every full historical native observation and all parent contexts. County pages separately contain every whole GIS object, safely HTML-escaped. Source-native object IDs are source identifiers only.

`previews/<FIPS>.svg` contains exact closed linear-ring positions in native-coordinate SVG paths, with a display Y flip only. Every coordinate and duplicate remains in order; no automatic ring closure is applied. True curves and open/short rings are omitted and labeled; raw source geometry remains complete. No point location is fabricated. Native source area/length attributes are not overwritten by numerical diagnostics.

`qa/geometry-diagnostics.json` records each source geometry's ring/point count, native validity/empty/curve/orphan-hole classification, exact XY IEEE754 preservation through inspected installed constructors, native square-metre overlap diagnostics and exclusions. Source invalids remain invalid. `qa/*installed-constructor.txt` preserves inspected constructors, which can auto-close; the adapter verifies source closure before construction. No SHP ZIP was acquired; no shapefile-member/CRC/DBF/SHX audit or ZIP-based service completeness claim is made.

`qa/pdf/**` retains full text/info/warnings/automatic whole-page renders from both complete county PDF originals. Manual scope explicitly names actual whole-page and selected dense/title detail images viewed. Automated rendering is not used to infer manual review. `qa/atlas-proof.json` checks parsed actual HTML details and runs actual filter JS in Node against those parsed rows; it is not a live-browser visual claim. `qa/fixtures/**` retains complete actual packets, including invalid JSON histories, with expected exact rejection outputs. Never admit invalid fixtures as current data.

Set `PYTHONDONTWRITEBYTECODE=1` for every command. From repository root:

```
python3 -B senate/2026/arkansas/maps/scripts/replay_authority.py
python3 -B senate/2026/arkansas/maps/scripts/original_body_audit.py
python3 -B senate/2026/arkansas/maps/scripts/negative_fixtures.py
python3 -B senate/2026/arkansas/maps/scripts/atlas_qa.py
python3 -B senate/2026/arkansas/maps/scripts/offline_reconstruction.py
python3 -B senate/2026/arkansas/maps/scripts/validate.py --sealed
```

`build.py --out <temporary-directory>` reconstructs atlas/native inventories from whole originals and frozen contract only. `offline_reconstruction.py` executes that reconstruction in a temporary tree with audit hooks denying network, subprocesses, mutable helper/aggregate/peer/writer reads, external discovery and writes outside temporary outputs; a separate parent compares every output size/SHA to retained complete bytes. This is the normal exact offline reproduction route. Source graph replay independently reads all complete roots/companions, all ordered recursive objects/partitions, every whole archive/member and original/receipt pin, all candidate/header/party/null/method/admin/context/order/crossing/parent arrays, without executing producer code. Scenarios/calculators/targets/outcomes and future-peer equality are outside its semantic scope.

Acquisition scripts use bounded public GET only and must not overwrite evidence. `native_download.py` uses only observed IDs, <=50 disjoint pages, all fields/native CRS/Z/M/truecurves plus pre/post metadata/count/ALLIDs; `county_controls.py` uses returned literal county field options. They are never part of offline reproduction. A future fetch must have a new label and preserve every hop/body/error. No account/private route/outreach/contact form is used.

Failure histories preserve entire prior checker/input/error before narrow fixes. `final-seal.json` is written first; `asset-manifest.json` LAST includes every owned file except itself, including report/CSV/original/history/script/proof/validation/seal. No current-manifest reverse digest cycle exists. Final `--sealed` is read-only and checks complete membership/hash/size/source/history/order/links/negative/offline scope. There must be no owned writes after its passing run; necessary repair requires retained prior bytes and a new full final seal/audit. No cache or dependency directory is retained. All current/legal/geography/eligible-write-in/reporting/leaf/November/cadence/pool/collector/forecast/calibration approval remains false/unknown.
