# Michigan official election-night publication channels

Research date: **2026-10-17**. This is an adapter inventory, not a running ingestion service. All observations below were retrieved on that date unless an election/publication date is explicitly stated. Historical examples do not establish 2026 schemas or reporting cadence.

The [SOS county directory](https://www.michigan.gov/sos/elections/election-results-and-data/candidate-listings-and-election-results-by-county) is the statewide authority chain: it links all 83 county election sites, says they may publish unofficial election-night results, and distinguishes those returns from certified results. Use the county channels for early observations. The [SOS August 4, 2026 night statement](https://www.michigan.gov/sos/resources/news/2026/08/04/deputy-secretary-reports-safe-secure-election-day-after-polls-close-across-michigan) says clerks report on their websites through the night and statewide results become available at Michigan.gov/Vote after all counties report. Its roughly 24-hour expectation concerns that primary, not a November service guarantee.

## Inventory, evidence, and verification levels

[data/official-results-sources.csv](data/official-results-sources.csv) contains **83 county rows plus SOS/BOE, participation dashboard, and Detroit rows**. Each county retains the exact SOS-linked URL, resolved URL, request status, authority URL, dated evidence filename, discovered result links, and explicitly untested feed status. A landing HTTP 200 is not proof of a functioning result feed or even a current election page. There are 73 HTTP-200 county landing fetches, seven HTTP-403 responses, two timeouts (Jackson and Marquette), and one HTTP-406 response (Ogemaw). Jackson subsequently worked at its alternate official domain. Kalamazoo and Berrien were readable through web search/open despite direct retrieval failures. Wayne's old domain returned a redirect helper rather than results. Follow-up web rendering confirmed current Kent pages and official vendor links despite raw HTTP403; Wayne remained blocked to web open but its current pages were indexed by search. No county is silently dropped.

`data/results-sources/directory.html` is the saved public directory; `directory-links.json` is the 83-link extract. Each county JSON is a bounded landing-page **text/link extract**, with URL, retrieval UTC, HTTP status, original-response byte length and SHA-256. These are derived evidence, not original HTML. Complete small raw samples have `.meta.json` URL/retrieval/status/checksum records and `.headers` files. Some server responses are gzip bytes despite an `.html` or `.json` filename; `.decoded` files are derived decompressions. Source timestamps/timezones are **unverified unless explicitly discussed below**; HTTP Last-Modified is transport metadata, not necessarily vote-update time.

Reproduce with Python 3 and curl:

```sh
python3 senate/2026/michigan/data/results-sources/inventory.py
python3 senate/2026/michigan/data/results-sources/deep_inspect.py
python3 senate/2026/michigan/data/results-sources/check_sample.py
python3 senate/2026/michigan/data/results-sources/finalize_inventory.py
```

The first script reuses existing county evidence; remove only the particular evidence file to request a refresh. `sample_fetch.py NAME=URL` saves bounded explicit public URLs, headers and metadata. Do not replace the observed historical version with a guessed future one. `finalize_inventory.py` adds documented second-level discoveries. SHA-256 manifest covers the delivered evidence and scripts; rerunning changes retrieval provenance and requires rebuilding that manifest. FIPS follow Michigan county ordering, with explicit correction for Saint Clair/Saint Joseph versus the directory's placement after Shiawassee; they are keys, not vendor IDs.

## Working public JSON example: Genesee 2024

Authority: county landing links Clarity election **122430**, November 5, 2024. Raw public application HTML shows `web.345435`; its JavaScript defines `current_ver.txt` and versioned JSON routes. [Version pointer](https://results.enr.clarityelections.com/MI/Genesee/122430/current_ver.txt) returned **355584**. Public endpoints actually downloaded:

- [Summary](https://results.enr.clarityelections.com/MI/Genesee/122430/355584/json/en/summary.json): array of contests; `C` name, `K` contest key, `CH` candidate labels, `P` parties, `V` vote array, `T` total, `PR`/`TP` reporting-unit counts. Senate `K="87"`; **not a 2026 ID**.
- [Details](https://results.enr.clarityelections.com/MI/Genesee/122430/355584/json/details.json): `Contests`, each with `K`, `P` unit-label array, `V` unit-by-candidate matrix, `T` row totals. Here `P` means precinct labels, not parties. Senate `Eid` and `Cid` arrays are empty. Example label: `Argentine Township, Precinct 1`. Preserve county, jurisdiction/full label, source version and array index; do not invent stable numeric precinct IDs.
- [Sum](https://results.enr.clarityelections.com/MI/Genesee/122430/355584/json/sum.json): separate summary structure, `Contests`; values include county ballots/registration where the English display summary has zero placeholders. In the observed Senate summary, `BC=0` and `TV=0` **must not** be treated as actual zero ballots/registration.
- [Status](https://results.enr.clarityelections.com/MI/Genesee/122430/355584/json/status.json): parallel `P,S,R,B,C,CONTEST` arrays; inspected `S` values are 4, and saved app code calls enum value 4 `CompletelyReported`. This is a vendor reporting status, not independently measured remaining votes.
- [Config](https://results.enr.clarityelections.com/MI/Genesee/122430/355584/json/config.json): `languages`, `lang`, `isPublished`, `versionTemplate`. A code-derived `electionsettings.json` request returned **404**. The redirect shell's `versions.txt` also returned **404**, although `current_ver.txt` works. Do not treat all code-mentioned files as deployed APIs.

`check_sample.py` verifies all **156** Senate detail-unit rows: candidate-column sums equal summary votes; each unit's candidate sum equals its row total; all candidate votes sum to **219,459**, including Slotkin **114,995** and Rogers **97,999**. `PR=TP=156` agrees with row count. These are calculated checks on the saved historical vendor snapshot, not a separate certification claim. The summary/details have no inspected voting-method dimension: a geographic precinct total may already combine methods. No exact remaining-vote estimate or vote-update timestamp/timezone was established. The app's version pointer supports replacement snapshots; it does not demonstrate a guaranteed polling cadence. `IsCumulative` is null in this non-cumulative-voting contest: it must not be interpreted as an incremental-feed flag. Adapter inference: totals describe the current full snapshot, so replace/reconcile them rather than add successive fetches.

Raw app JS exceeded the 2.5 MB sample cap and was truncated (curl failure preserved in metadata). Only small relevant derived excerpts are retained, with original partial-response checksum/headers; that file is not a complete app bundle. The JSON samples themselves are complete and successfully decoded. A second historical-night snapshot was unavailable, so actual batch timing/correction behavior was not replayed.

## Counting rules, time, and operational traps

Current [SOS Election Day guidance](https://www.michigan.gov/sos/elections/voting/vote-on-election-day), retrieved 2026-10-17, says polls run 7 a.m.–8 p.m. **local time**. Do not translate every county to the same UTC instant. The current [49 CFR 71.5 boundary source](https://www.ecfr.gov/current/title-49/subtitle-A/part-71/section-71.5) redirected to an access-challenge page here: current official county-by-county timezone verification remains a gap. Operational candidate assignment is Eastern except Dickinson, Gogebic, Iron, Menominee in Central, **pending authoritative current boundary verification**, not an adapter-validated fact. On Nov. 3, use timezone-aware conversions (`America/Detroit`/`America/Menominee`) only after confirming local polling notices; ordinary 8 p.m. Eastern/Central conversions are 01:00/02:00 UTC Nov. 4. Do not reuse the older SOS 2020 press PDF's inconsistent “3 counties” count.

Current [SOS early-voting FAQ](https://www.michigan.gov/sos/faqs/elections-and-campaign-finance/early-in-person-voting), retrieved 2026-10-17, states early-vote precinct totals are published only after polls close. Tabulation before Election Day does not mean those votes should already be in public results. [Current absentee guidance](https://www.michigan.gov/sos/elections/voting/absentee-voting) permits eligible jurisdictions of at least 5,000 residents to establish AVCBs to process/tabulate during the eight days before an election; all jurisdictions can do so on Monday before Election Day. The page distinguishes ordinary receipt deadlines from military/overseas ballots postmarked by Election Day and received within six days. These rules do not establish how many ballots remain in any county. [SOS security guidance](https://www.michigan.gov/sos/elections/security) explains that county canvassers compare physical tabulation records and correct unofficial reporting errors before certification.

Adapter requirements inferred from those rules and inspected formats:

1. Save source bytes/version/UTC retrieval and official status at every observation. Validate election date and contest/candidate identities before ingesting. Reject HTML challenge/redirect/app shells as data even on HTTP 200. Keep gzip/content-type handling explicit.
2. Poll conservatively, back off on errors and use conditional requests where supported. No source in this inspection established guaranteed live cadence. Never call a stale archive “live.” Fetch the version pointer then pin all related files to that version; detect version changes during a multi-file read.
3. Replace cumulative totals; preserve decreases and revisions. Never sum state, county and Detroit overlaps, PDFs plus vendor totals, or county totals plus their precincts. Keep raw candidate arrays aligned and include write-ins/third parties.
4. `PR/TP`, reporting-board percentages and “complete” do not measure vote completion. Geographic precincts, AVCBs and early-voting units may differ. No inspected feed supplies a validated exact outstanding-ballot count. Keep that field null; never calculate it as registered voters minus ballots or votes times unreported-unit percentage.
5. Manual fallback: open the official clerk landing, follow its actual election link, save PDF/screenshot or transcribe county/contest/method/unit totals with publication label, URL and UTC time. Record unavailable fields as null and obtain review before merging. Broken-host fallback must retain the official authority chain; a search result or news aggregator alone does not authorize a vendor feed.
